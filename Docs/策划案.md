## 4. 核心战斗设计

### 4.1 攻击与连招
- 玩家近战 **5 段连招**（Attack1–5，动画已解包配好）
- **连招窗口内按键连打派生**下一段，错过窗口就停（还原只狼"预输入 + 连段"手感）
- 轻重攻击通过不同 `AttackConfig` 区分（不通过命令字段，见 `total.md` 决策 9）

### 4.2 防御 / 弹反（方案 B：只狼式输入）
- **短按（<0.15s）= 弹反**：播独立"弹反 / 甩刀"动画，动画期间为弹反窗口
- **长按（≥0.15s）= 格挡**：持续举刀防御姿态
- **格挡**：不扣血，只涨架势
- **完美弹反**：涨 Boss 架势 + 敌人被弹开硬直；自己涨**少量**架势，但**永不因此崩解**（架势快满时完美弹反不破防）
- **弹反窗口**：0.3s（基础值）
- **抖刀惩罚**：0.5s 内连点防御 ≥3 次 → 每次窗口 ×0.75，下限 0.1s；停止点击 0.5s 后恢复

### 4.3 架势系统（非线性回复）
- 架势满 → 崩解
- **玩家架势回复**：停止受击 2s 后回复 20/s；**按住格挡（2s 后）回复 ×5**
- **Boss 架势回复**：架势越高回复越慢 —— `恢复速度 = 基础速度 × (1 − 当前架势 / 最大架势)`（"反函数"手感，越低越快）
- **玩家架势崩解**：击飞 → 倒地（专门动画），不被 Boss 处决，随后架势清空
- **Boss 架势崩解**：进入处决窗口 5 秒，红点提示

### 4.4 垫步
- 有 **0.3s 无敌帧**
- 方向：锁定后绕目标侧向、未锁定朝输入方向

### 4.5 危字攻击
- **突刺** → 识破（踩刀，涨攻击者架势；代码已实现）
- **投技 Grab（肘击）** → 弹反窗口弹开 / 垫步躲避（代码已实现）
- ~~**横扫** → 跳踩反制~~（已删除：未实现跳踩反制，Boss 无横扫招式）
- 射箭、飞渡符舟是普通攻击（可格挡 / 弹反）
- "危"字 UI 提示保留

### 4.6 处决 / 忍杀
- Boss 架势崩解 → 红点 → 走近**按攻击键**触发处决 → 清 1 条命
- 一阶段 2 条命，清完直接胜利

### 4.7 葫芦 / 复活 / 死亡
- **葫芦**：一次**回满血**；有喝药动画 + 硬直，**会被打断**（如蓄力重箭）
- **复活**：回生动画 + 无敌帧；复活后 Boss **不重置**，接着打
- **死亡重开**：按键重开 / 重新加载场景

### 4.8 锁定与镜头
- **手动按键锁定**（中键锁定 / 解锁，单 Boss 不做切目标）
- Cinemachine：FreeLook（自由）+ TargetGroup（锁定）+ Impulse（震屏）
- 锁定后移动相对目标（绕圈），未锁定相对相机

### 4.9 打击感
- 命中 / 弹反做 **hitstop（短暂停顿）+ 打铁火花**
- 格挡 = 小火花 + 沉闷"笃"声；弹反 = 大火花 + 清脆"叮"声

### 4.10 受击
- 区分**地面 / 空中受击动画**

## 5. Boss 弦一郎（一阶段）

- **招式**：近战连段 + 突刺（危字/识破）+ 横扫（危字/跳踩）+ 射箭（普通）+ 飞渡符舟（普通，完整动画）
- **AI 三层**：
  1. **主动进攻**：按距离分段选招
  2. **交锋计划**：被弹开后变招（完美弹反让 Boss 硬直并触发变招）
  3. **防御 / 招架**：玩家攻击时防御，完美弹反会弹开玩家（小硬直）
- **命数**：一阶段 2 条命（原作共 3 命，二阶段后补）

## 6. 数值基准

> 全部走 ScriptableObject（`CharacterConfig` / `AttackConfig`），Unity Inspector 里可调。下表为**基准值**。

| 对象 | 属性 | 基准值 |
|------|------|--------|
| 玩家 | MaxHP | 1000 |
| 玩家 | MaxPosture | 100 |
| 玩家 | 架势回复 | 20/s（格挡 ×5），延迟 2s |
| 玩家 | 葫芦 | 10 次，回满血 |
| 玩家 | 复活 | 1 次，回满 + 无敌帧 |
| Boss | MaxHP | ~4000（约 80 刀打死） |
| Boss | MaxPosture | 100 |
| Boss | 单刀伤害 | ~250–330（满血吃 3–4 刀死） |
| 通用 | 弹反窗口 | 0.3s（抖刀惩罚下限 0.1s） |
| 通用 | 垫步无敌帧 | 0.3s |
| 通用 | 处决窗口 | 5s |

**胜负逻辑（核心）**：打 Boss 不靠血量，靠「进攻命中 + 完美弹反」持续涨 Boss 架势 → 崩解 → 处决 → 清命 → 再压制 → 处决 → 胜利。血量只是容错。

## 7. 技术架构

| 系统 | 技术选型 |
|------|---------|
| 状态机 | HFSM（顶层只放父状态 Grounded/Air/Stunned，叶子在 SubStateMachine） |
| 战斗驱动 | 命令模式（Command）+ 受击路由（`OnHitReceived` 层级查询） |
| Boss AI | 行为树（黑板 + Running 记忆） |
| 命中判定 | 动画事件 + `Physics.BoxCast/SphereCast`（不用 OnTrigger） |
| 伤害数据 | `AttackConfig`（SO） |
| 角色属性 | `CharacterConfig`（SO） |
| 表现层 | 事件总线 `CombatEventBus` + FX / 音效管理器 |
| 相机 | Cinemachine（FreeLook + TargetGroup + Impulse） |
| UI | MVC + DoTween |
