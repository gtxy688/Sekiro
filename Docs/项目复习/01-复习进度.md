## 代码事实与验证边界

- 源码已确认：`PlayerInput` 通过 Unity New Input System 回调将离散操作转为 Command，连续摇杆直接赋给 `body.MoveDirection`。
- 源码已确认：`AttackCommand` 轻击在 `OnAttackCanceled` 入池，长按突刺在 `ProcessHeldAttack` 中经蓄力阈值由 `Update` 注入；忍杀在 `OnAttackStarted` 优先抢占。
- 源码已确认：`DeflectCommand` 携带自增 `pressId`，仅 `Started` 生成指令，`Canceled` 仅通知 `NotifyDeflectReleased`。
- 源码已确认：`BrainBase` 维持单槽 0.2s 预输入缓冲池（`bufferedCommand` + `bufferTimer`），`Update` 驱动 `ProcessCommandBuffer`。
- 本轮只静态核对源码与简历；未运行 Unity、未验证场景绑定或实际手感，也未开展性能测量。
