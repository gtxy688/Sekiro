## 1. 架势崩解、失衡恢复与弹反确认窗口（CombatStats → ForcePostureBroken → StaggerBrokenState / FinisherReadyState）

在战斗中，角色（玩家或 Boss）的架势值（`CurrentPosture`）在肉身受击、格挡受击、被完美弹反或危字突刺被识破时持续累积。当 `CurrentPosture >= config.MaxPosture` 且本次累加允许崩解（`allowBreak == true`）时，`CombatStats.AccumulatePosture` 将 `IsPostureBroken` 置为 `true`，记录崩解来源 `CurrentPostureBreakSource`，并通过构造函数注入的委托 `onPostureBreak(source)` 回调 `CharacterBody.ForcePostureBroken(source)`。

### 1.1 架势打满触发崩解与超时恢复的完整调用树

```text
[触发路径 A：肉身受击或格挡受击打满架势（source = PostureBreakSource.Attack）]
CharacterBody.ReceiveHit(attacker, healthDmg, postureDmg, ...)
  ├── [格挡分支] DeflectState.OnHitReceived(hit)
  │     └── body.AccumulatePosture(postureCost, allowBreak: true)
  └── [肉身分支] CharacterBody.TakeDamage(healthDmg, postureDmg, attacker)
        └── CombatStats.TakeDamage(healthDmg, postureDmg, instigator)
              └── CombatStats.AccumulatePosture(postureDmg, true, PostureBreakSource.Attack, instigator)
                    └── [CurrentPosture >= maxPosture]
                          ├── IsPostureBroken = true
                          ├── CurrentPostureBreakSource = source
                          ├── CombatEventBus.TriggerPostureBroken(body)
                          ├── CombatEventBus.TriggerFinisherOpportunityChanged(body, true)
                          └── onPostureBreak(source) ──► CharacterBody.ForcePostureBroken(PostureBreakSource.Attack)
                                └── EnterGrounded(new StaggerBrokenState(this), "combat: posture broken")

[触发路径 B：玩家完美弹反打满 Boss 架势（source = PostureBreakSource.Deflect）]
DeflectState.HandlePerfectParry(hit)
  ├── attacker.AccumulatePosture(parryPostureToAttacker, allowBreak: true, source: PostureBreakSource.Deflect, instigator: body)
  │     └── [Boss 架势打满] onPostureBreak(PostureBreakSource.Deflect)
  │           └── Boss.ForcePostureBroken(PostureBreakSource.Deflect)
  │                 └── Boss.EnterGrounded(new FinisherVictimState(this, "Stagger_Broken_Deflect"), "combat: posture broken")
  └── [attackerBroken == true 且防守方为玩家]
        └── parent.SubStateMachine.ChangeState(new FinisherReadyState(body, parent, attacker))

[触发路径 C：玩家垫步识破危字突刺打满 Boss 架势（source = PostureBreakSource.Mikiri）]
DodgeState.OnHitReceived(hit)
  └── parent.SubStateMachine.ChangeState(new MikiriCounterState(body, parent, hit))
        └── MikiriCounterState.OnEnter()
              └── attacker.AccumulatePosture(postureGain, allowBreak: true, source: PostureBreakSource.Mikiri)
                    └── [Boss 架势打满] onPostureBreak(PostureBreakSource.Mikiri)
                          └── Boss.ForcePostureBroken(PostureBreakSource.Mikiri)
                                └── Boss.EnterGrounded(new FinisherVictimState(this, "Stagger_Broken_Mikiri"), "combat: posture broken")

[驱动源头：每帧驱动失衡倒地计时或确认窗口计时，超时自动恢复]
CharacterBody.Update() [Unity MonoBehaviour 每帧调用]
  └── MainStateMachine.Update()
        └── GroundedState.OnUpdate()
              └── base.OnUpdate() [HierarchicalState.OnUpdate()]
                    └── SubStateMachine.Update()
                          ├── [普通崩解分支] StaggerBrokenState.OnUpdate()
                          │     ├── [达到取消时间 BrokenDeflectDodgeOpenTime 且收到格挡/闪避指令]
                          │     │     └── StaggerBrokenState.HandleCommand(cmd)
                          │     │           ├── body.TryChangeToDeflectOrDodge(...)
                          │     │           └── body.ClearPostureBreak()
                          │     └── [动画播完 normalizedTime >= 0.99f 或 timer >= duration]
                          │           └── StaggerBrokenState.FinishBreak()
                          │                 └── body.RecoverFromBreak(0f) ──► 清空架势并切回 GroundedState(IdleState)
                          └── [弹反打崩确认分支] FinisherReadyState.OnUpdate()
                                └── [DeflectToFinsher 动画 normalizedTime >= 0.95f 未按攻击键]
                                      └── FinisherReadyState.ExpireWindow()
                                            ├── victim.RecoverFromBreak(0.8f) ──► 解除 Boss 崩解并保留 80% 架势
                                            └── parent.SubStateMachine.ChangeState(new IdleState(body, parent))
```

### 1.2 三种崩解来源与目标状态分流

`CharacterBody.ForcePostureBroken` 根据传入的 `PostureBreakSource` 决定进入哪个地面子状态：

| 崩解来源（`PostureBreakSource`） | 触发场景 | Boss 进入的子状态与动画 | 玩家进入的子状态与动画 | 超时未处决的恢复结果 |
| :--- | :--- | :--- | :--- | :--- |
| `Attack` | 普攻肉身命中或格挡架势打满 | `StaggerBrokenState`（播 `HurtAnim_Broken`） | `StaggerBrokenState`（播 `HurtAnim_Broken`） | 动画播完调用 `RecoverFromBreak(0f)`，架势归零并回 `IdleState` |
| `Deflect` | 玩家完美弹反打满 Boss 架势 | `FinisherVictimState`（播 `Stagger_Broken_Deflect`），同时玩家进 `FinisherReadyState` | 玩家完美弹反不崩防；若其他原因传入则回退 `StaggerBrokenState` | 玩家 `FinisherReadyState` 播完调 `victim.RecoverFromBreak(0.8f)`，Boss 保留 80% 架势回 `IdleState` |
| `Mikiri` | 玩家无方向垫步识破危字突刺打满 Boss 架势 | `FinisherVictimState`（播 `Stagger_Broken_Mikiri` / `Miriki`），同时玩家处于 `MikiriCounterState` | 回退 `StaggerBrokenState` | 玩家 `MikiriCounterState` 播完调 `attacker.RecoverFromBreak(0.8f)`，Boss 保留 80% 架势回 `IdleState` |

### 1.3 `CombatStats` 架势累积与崩解恢复真实源码

```csharp
// 统一累计伤害、格挡或弹反带来的架势，并在达到上限时通知角色崩解。
// 架势是累积到满条才崩解的压力值，与越扣越少的 HP 方向相反。
// allowBreak=false 只累加但不触发崩解；返回 true 仅表示本次确实触发了崩解。
public bool AccumulatePosture(
    float amount,
    bool allowBreak = true,
    PostureBreakSource source = PostureBreakSource.Attack,
    CharacterBody instigator = null)
{
    if (IsPostureBroken) return false; // 崩解中不累计

    CharacterConfig config = body.Config;
    float maxPosture = config.MaxPosture;

    if (allowBreak && amount > 0f
        && GameplaySettings.ShouldOneHitBreakBoss(body, source, instigator))
    {
        CurrentPosture = maxPosture;
        MarkCombatTime();
        CombatEventBus.TriggerPostureChanged(body, CurrentPosture, maxPosture);
        IsPostureBroken = true;
        CurrentPostureBreakSource = source;
        CombatEventBus.TriggerPostureBroken(body);
        CombatEventBus.TriggerFinisherOpportunityChanged(body, true);
        onPostureBreak(source);
        return true;
    }

    CurrentPosture = Mathf.Min(CurrentPosture + amount, maxPosture);
    MarkCombatTime();

    CombatEventBus.TriggerPostureChanged(body, CurrentPosture, maxPosture);

    if (allowBreak && CurrentPosture >= maxPosture)
    {
        IsPostureBroken = true;
        CurrentPostureBreakSource = source;
        // 崩解 → 崩解硬直（玩家击飞倒地 / Boss 处决窗口）
        CombatEventBus.TriggerPostureBroken(body);
        CombatEventBus.TriggerFinisherOpportunityChanged(body, true);
        onPostureBreak(source);
        return true;
    }

    return false;
}

// 崩解标志/架势条清掉，不切状态。倒地中再挨刀时先清再进受击，避免闪 Idle。
public void ClearPostureBreak(float remainingRatio = 0f)
{
    IsPostureBroken = false;
    CharacterConfig config = body.Config;
    float maxPosture = config.MaxPosture;
    CurrentPosture = Mathf.Clamp01(remainingRatio) * maxPosture;
    CombatEventBus.TriggerPostureChanged(body, CurrentPosture, maxPosture);
    CombatEventBus.TriggerFinisherOpportunityChanged(body, false);
}
```

### 1.4 `CharacterBody.ForcePostureBroken` 与 `RecoverFromBreak` 真实源码

```csharp
// 架势崩解硬直入口：玩家 = 击飞倒地（不被处决）；Boss = 处决窗口（红点）。
public void ForcePostureBroken(PostureBreakSource source = PostureBreakSource.Attack)
{
    AttackUninterruptible = false;
    DisableWeaponHit();
    KengekiArmed = false;
    CombatEventBus.TriggerCameraShake(0.8f); // 崩解震屏

    // 弹反/识破受害姿态只给 Boss：玩家没有这些状态，崩解走普通击飞倒地。
    BaseState brokenState;
    switch (source)
    {
        case PostureBreakSource.Deflect:
        {
            string deflectAnim = AnimUtil.ResolveState(Animator, "Stagger_Broken_Deflect");
            brokenState = deflectAnim != null
                ? new FinisherVictimState(this, deflectAnim)
                : new StaggerBrokenState(this);
            break;
        }
        case PostureBreakSource.Mikiri:
        {
            string mikiriAnim = AnimUtil.ResolveState(
                Animator, "Stagger_Broken_Mikiri", "Stagger_Broken_Miriki");
            brokenState = mikiriAnim != null
                ? new FinisherVictimState(this, mikiriAnim)
                : new StaggerBrokenState(this);
            break;
        }
        default:
            brokenState = new StaggerBrokenState(this);
            break;
    }

    EnterGrounded(brokenState, "combat: posture broken");
}

// 崩解标志/架势条清掉，不切状态。倒地中再挨刀时先清再进受击，避免闪 Idle。
public void ClearPostureBreak(float remainingRatio = 0f)
{
    Combat.ClearPostureBreak(remainingRatio);
}

// 崩解超时恢复：架势清空 + 崩解解除，不扣命（与处决清命区分）
public void RecoverFromBreak(float remainingRatio = 0f)
{
    ClearPostureBreak(remainingRatio);
    EnterGrounded("combat: recover from posture break");
}
```

### 1.5 `StaggerBrokenState` 与 `FinisherReadyState` 生命周期及真实源码

- **继承与重写关系**：
  - `StaggerBrokenState` 直接继承自 `BaseState`。重写了 `OnEnter()`、`OnUpdate()`、`HandleCommand(ICommand cmd)`；**未重写** `OnExit()` 与 `OnHitReceived(HitData hit)`（直接执行父类 `BaseState` 的空实现与默认返回 `false`）。
  - `FinisherReadyState` 直接继承自 `BaseState`。重写了 `OnEnter()`、`OnUpdate()`、`HandleCommand(ICommand cmd)`、`OnHitReceived(HitData hit)`；**未重写** `OnExit()`。
- **关键状态保护**：
  - `StaggerBrokenState.OnUpdate()` 使用 `seenStart` 标志确保先观察到 `info.normalizedTime < 0.5f`，之后才允许在 `info.normalizedTime >= 0.99f` 时调用 `FinishBreak()`，防止切入动画当帧因残留上一动画末尾进度而瞬间解除崩解。
  - 当 `timer >= body.BrokenDeflectDodgeOpenTime`（玩家配置了起身取消门槛，Boss 配置为 `0` 不开放）时，玩家可通过 `DeflectCommand` 或 `DodgeCommand` 提前切入防御或垫步，并同步调用 `body.ClearPostureBreak()` 清空架势条。

```csharp
// 播放架势崩解倒地动画，结束后解除崩解；Boss 在此期间可被普通忍杀。
// 达到配置时刻后可取消到格挡或垫步，并同步清除崩解数值。
// 崩解数值已在 CombatStats 中设置，本状态只管理倒地表现、输入限制与恢复时机。
public class StaggerBrokenState : BaseState
{
    // Animator 当帧还没切到 clip 时的兜底：玩家 Stagger_Broken 约 75 帧 / 30fps
    private const float FallbackDuration = 2.5f;

    private string animName;
    private float timer;
    private float duration;
    private bool triedNestedPath;
    private bool seenStart;

    public bool CanDeflectOrDodgeCancel
    {
        get
        {
            float open = body.BrokenDeflectDodgeOpenTime;
            // 配置单位是入场后的秒数；<= 0 表示不开放提前取消。
            return open > 0f && timer >= open;
        }
    }

    public StaggerBrokenState(CharacterBody body) : base(body)
    {
    }

    public override void OnEnter()
    {
        timer = 0f;
        triedNestedPath = false;
        seenStart = false;
        duration = FallbackDuration;
        animName = !string.IsNullOrEmpty(body.Config.HurtAnim_Broken)
            ? body.Config.HurtAnim_Broken : "Hurt_Ground";

        if (!AnimUtil.TryPlay(body.Animator, animName))
        {
            Debug.LogError($"{body.name} 的 Animator 缺少崩解状态：{animName}");
            duration = 0.5f;
        }
    }

    public override void OnUpdate()
    {
        timer += Time.deltaTime;
        AnimatorStateInfo info = body.Animator.GetCurrentAnimatorStateInfo(0);
        if (AnimUtil.IsPlaying(info, animName))
        {
            // Play(0) 当帧可能仍带着上一圈末尾的 normalizedTime>=0.99。
            // 必须先看到开头，否则会立刻 RecoverFromBreak，后续连段被 StunnedState 二次受击全吞。
            if (info.normalizedTime < 0.5f)
            {
                seenStart = true;
                if (info.length > 0.05f)
                {
                    duration = info.length;
                }
            }

            if (seenStart && info.normalizedTime >= 0.99f && !body.Animator.IsInTransition(0))
            {
                FinishBreak();
                return;
            }
        }
        else if (!triedNestedPath && timer > 0.05f)
        {
            // 等待进入请求生效，仍未匹配时再尝试播放一次。
            triedNestedPath = true;
            AnimUtil.TryPlay(body.Animator, animName);
        }

        // 短名对不上或 clipInfo 为空时，仍按兜底时长结束，避免满条卡死。
        if (timer >= duration)
        {
            FinishBreak();
        }
    }

    public override bool HandleCommand(ICommand cmd)
    {
        // 达到取消时刻后可切格挡或垫步；系统回防的 PressId 为 0，不开主动弹反窗口。
        if (cmd is DeflectCommand || cmd is DodgeCommand)
        {
            int pressId = cmd is DeflectCommand deflectCmd ? deflectCmd.PressId : 0;
            if (CanDeflectOrDodgeCancel &&
                body.TryChangeToDeflectOrDodge(cmd is DeflectCommand, pressId))
            {
                // 架势条同步清空（与 RecoverFromBreak 一致），留在同一个 GroundedState 里只换子状态，
                // 不走 RecoverFromBreak 重建顶层（会掐断垫步/抬刀的进场）。
                body.ClearPostureBreak();
                return true;
            }

            // 窗口未到 / 锁定期间未实际开启窗口：不消耗，留缓冲重试（格挡键可长按），也不记空按
            return false;
        }

        return true;
    }

    private void FinishBreak()
    {
        // 不能只切 Idle：RecoverFromBreak 同时清崩解数值与忍杀机会，再恢复地面待机。
        body.RecoverFromBreak();
    }
}
```

```csharp
// 完美弹反打崩 Boss 后的玩家确认窗口。
// 窗口长度由 DeflectToFinsher 动画决定，超时后解除 Boss 崩解并保留 80% 架势。
// DeflectState 在成功弹反并打崩对手后切入；此时还没有开始成对忍杀演出。
public class FinisherReadyState : BaseState
{
    private const string ReadyAnim = "DeflectToFinsher";

    private readonly HierarchicalState parent;
    private readonly CharacterBody victim;
    private bool hasSeenReadyAnim;

    public FinisherReadyState(
        CharacterBody body,
        HierarchicalState parent,
        CharacterBody victim) : base(body)
    {
        this.parent = parent;
        this.victim = victim;
    }

    public override void OnEnter()
    {
        hasSeenReadyAnim = false;

        if (!AnimUtil.HasState(body.Animator, ReadyAnim))
        {
            Debug.LogError($"{body.name} 的 Animator 缺少弹反忍杀确认状态：{ReadyAnim}");
            ExpireWindow();
            return;
        }

        AnimUtil.TryCrossFade(body.Animator, ReadyAnim, 0.05f);
    }

    public override void OnUpdate()
    {
        AnimatorStateInfo info = body.Animator.GetCurrentAnimatorStateInfo(0);
        if (AnimUtil.IsPlaying(info, ReadyAnim))
        {
            hasSeenReadyAnim = true;
            if (info.normalizedTime >= 0.95f)
            {
                ExpireWindow();
            }
        }
        else if (hasSeenReadyAnim && !body.Animator.IsInTransition(0))
        {
            ExpireWindow();
        }
    }

    public override bool HandleCommand(ICommand cmd)
    {
        if (cmd is FinisherCommand)
        {
            // 本状态提出执行请求；CombatManager 统一检查目标和双方状态，并安排成对动作。
            CombatManager.Instance.TryExecuteFinisher(body, FinisherKind.Deflect);
        }
        return true;
    }

    public override bool OnHitReceived(HitData hit)
    {
        // 确认动作期间拦截普通受击；不是再次结算这次打崩对手的攻击。
        return true;
    }

    private void ExpireWindow()
    {
        if (victim != null && victim.IsPostureBroken)
        {
            victim.RecoverFromBreak(0.8f);
        }

        parent.SubStateMachine.ChangeState(new IdleState(body, parent));
    }
}
```

## 2. 忍杀机会判定与指令抢占路由（OnAttackStarted → FinisherCommand → 状态机四路分发）

普通轻攻击 `AttackCommand` 是在**松开攻击键**（`OnAttackCanceled`）时入池，以区分长按突刺；而忍杀处决必须在**按下攻击键当帧**（`OnAttackStarted`）立即响应，且绝不能让打崩 Boss 前残留在预输入缓冲池里的普通 `AttackCommand` 误触发忍杀或继续挥出普通下一刀。因此项目专门定义了独立的 `FinisherCommand`。

### 2.1 忍杀按键抢占与状态机路由调用树

```text
[阶段 1：攻击键按下当帧（InputAction.started 回调）]
PlayerBrain.OnAttackStarted(CallbackContext)
  └── CombatManager.Instance.HasAvailableFinisher(body)
        └── DuelDirector.HasAvailableFinisher(initiator)
              ├── 检查 CanInitiateFinisher(initiator) [仅 Faction.Player]
              ├── 检查 !initiator.IsPostureBroken && active == null
              ├── FindAnyBrokenOpponent(initiator) ──► 找到 IsPostureBroken == true 的 Boss
              └── CanExecuteFinisher(initiator, victim, FinisherKindFor(victim.CurrentPostureBreakSource))
                    ├── 校验双方 Animator 均存在对应 Finsher_* 状态
                    └── 若为 FinisherKind.Ground，校验距离 <= finisherRange (2f)；Deflect/Mikiri 不卡距离
  └── [返回 true：当前确有可执行忍杀]
        ├── attackPressed = false / holdAttackTriggered = false / holdThresholdChecked = true
        └── BufferCommand(new FinisherCommand())

[阶段 2：同帧或后续帧轮询缓冲池分发 FinisherCommand]
PlayerBrain.Update()
  └── BrainBase.Update()
        └── BrainBase.ProcessCommandBuffer()
              └── CharacterBody.TryExecuteCommand(FinisherCommand)
                    └── MainStateMachine.HandleCommand(FinisherCommand)
                          └── GroundedState.HandleCommand(FinisherCommand)
                                ├── 1. GroundedState.OnParentHandleCommand(cmd)
                                │     └── [cmd is FinisherCommand]
                                │           ├── CombatManager.Instance.TryExecuteAvailableFinisher(body)
                                │           │     └── DuelDirector.TryExecuteAvailableFinisher(initiator)
                                │           └── return true（父层直接拦截消费，无论当前子状态是 Idle/Move/Attack/Deflect/FinisherReady/MikiriCounter）
                                └── 2. [防御性冗余：若子状态直接收到 FinisherCommand]
                                      ├── AttackStateBase.HandleCommand ──► HandleFinisherCommand() ──► TryExecuteAvailableFinisher(body)
                                      ├── FinisherReadyState.HandleCommand ──► TryExecuteFinisher(body, FinisherKind.Deflect)
                                      └── MikiriCounterState.HandleCommand ──► TryExecuteFinisher(body, FinisherKind.Mikiri)
```

### 2.2 输入层抢占与地面父状态拦截真实源码

在 `GroundedState.OnParentHandleCommand` 中，除了直接拦截 `FinisherCommand` 调起 `TryExecuteAvailableFinisher(body)` 外，还专门针对残留的 `AttackCommand` 做了防御性吞噬：当 `CombatManager.Instance.HasAvailableFinisher(body)` 为 `true` 时，任何早先缓存的普通 `AttackCommand` 直接返回 `true` 丢弃，既不会变成忍杀（必须重新按一次攻击键生成 `FinisherCommand`），也不会落到 `IdleState` / `AttackState` 挥出普通连招打乱处决节奏。

```csharp
// PlayerBrain.cs：按下攻击键当帧优先探测忍杀机会
private void OnAttackStarted(InputAction.CallbackContext _)
{
    if (!CanAcceptPlayInput()) return;

    // 按下时决定是否忍杀，避免普通攻击在松键或缓冲期间被改成忍杀。
    if (CombatManager.Instance.HasAvailableFinisher(body))
    {
        attackPressed = false;
        holdAttackTriggered = false;
        holdThresholdChecked = true;
        BufferCommand(new FinisherCommand());
        return;
    }

    // 从按下时开始计时，后续按持续时长区分普通攻击与突刺。
    attackPressed = true;
    holdAttackTriggered = false;
    holdThresholdChecked = false;
    attackPressedTime = Time.time;
}
```

```csharp
// GroundedState.cs（OnParentHandleCommand 尾部）：父层统一拦截 FinisherCommand 并丢弃过期普攻预输入
// 只有在崩解机会已经出现后新按的攻击键才会生成 FinisherCommand。
// 普通 AttackCommand 即使仍在连招缓冲中，也绝不能因本刀把 Boss 打崩而变成忍杀。
if (cmd is FinisherCommand)
{
    if (body.Faction == Faction.Player)
        CombatManager.Instance.TryExecuteAvailableFinisher(body);
    return true;
}

// Boss 已可忍杀时残留的普通攻击预输入直接丢弃，不能再落到 Idle/Move 开一刀。
if (cmd is AttackCommand &&
    body.Faction == Faction.Player &&
    CombatManager.Instance.HasAvailableFinisher(body))
{
    return true;
}
```

## 3. 双人同步处决演出与命数结算（DuelDirector → FinisherState & FinisherVictimState → ClearLife）

当 `TryExecuteAvailableFinisher` 或 `TryExecuteFinisher` 被调用时，`CombatManager` 将请求转发给同物体上的 `DuelDirector`。`DuelDirector` 负责校验双方条件、对齐双方水平朝向、上锁 `IsFinisherLocked = true`，并驱动玩家进入 `FinisherState`、Boss 进入 `FinisherVictimState`。

### 3.2 为什么成对处决“只对齐朝向、不瞬移位置”且“忽略胶囊体推挤”？

1. **只转朝向、不瞬移位置（`AlignFinisherFacing`）**：
   - 弹反忍杀（`Deflect`）与识破忍杀（`Mikiri`）触发前，双方已经通过刀剑相撞或踩刀动画处于贴身距离；普通地面忍杀（`Ground`）则由 `finisherRange = 2f` 限制触发距离。
   - 开演时调用 `player.SnapYaw(toBoss, playerAnim)` 和 `boss.SnapYaw(-toBoss, bossAnim)` 让双方严格水平对视，随后的位移完全交由双方成对制作的动画 Root Motion 推进，避免生硬的坐标瞬移穿帮。
2. **处决锁期间跳过胶囊体防重叠推挤（`ResolveOpponentOverlap`）**：
   - 平时玩家与 Boss 的物理碰撞体通过 `Physics.IgnoreCollision` 忽略刚体冲量互撞，由玩家的 `CharacterBody.LateUpdate() -> ResolveOpponentOverlap()` 调用 `Physics.ComputePenetration` 将玩家水平推出 Boss 胶囊体外。
   - 但在成对忍杀或投技演出期间，双方的成对骨骼动画需要近距离贴合甚至身体交错；因此 `ResolveOpponentOverlap()` 在开头检查 `if (IsFinisherLocked) return;`，确保成对动画的 Root Motion 轨迹不会被胶囊体分离逻辑强行推偏。

### 3.3 `DuelDirector` 处决编排与结算真实源码

```csharp
// 一次成对演出。处决与投技共用同一个槽位，因为它们本来就不可能同时发生。
private class PairedPerformance
{
    public CharacterBody Initiator;   // 处决发起者 / 投技攻击者
    public CharacterBody Victim;      // 被处决者 / 被投者
    public bool Resolved;             // 处决：已清命；投技：双方都已到点
    public bool InitiatorDone;        // 投技用：发起方 Clip 播完
    public bool VictimDone;           // 投技用：受方 Clip 播完
}

// 供输入层在按键按下当帧判断：只有此刻真的能开演，才生成 FinisherCommand。
// 不能用 TryExecuteAvailableFinisher 探测，它会直接切状态并消耗机会。
public bool HasAvailableFinisher(CharacterBody initiator)
{
    if (initiator == null || !CanInitiateFinisher(initiator)) return false;
    if (initiator.IsPostureBroken || active != null) return false;

    CharacterBody victim = FindAnyBrokenOpponent(initiator);
    if (victim == null) return false;

    return CanExecuteFinisher(
        initiator,
        victim,
        FinisherKindFor(victim.CurrentPostureBreakSource));
}

// ===== 成对忍杀=====
public bool TryExecuteFinisher(CharacterBody initiator, FinisherKind kind = FinisherKind.Ground)
{
    if (initiator == null) return false;
    if (!CanInitiateFinisher(initiator)) return false;
    if (initiator.IsPostureBroken) return false;
    if (active != null) return false;

    CharacterBody victim = FindFinisherVictim(initiator, kind);
    if (victim == null) return false;

    string playerAnim = ResolveFinisherAnim(kind, initiator.Animator);
    string bossAnim = ResolveFinisherAnim(kind, victim.Animator);
    if (string.IsNullOrEmpty(playerAnim) || string.IsNullOrEmpty(bossAnim))
    {
        Debug.LogError(
            $"成对忍杀状态缺失：{kind}。请同时检查 {initiator.name} 与 {victim.name} 的 Animator（Mikiri/Miriki 拼写都算）。");
        return false;
    }

    // 弹反/识破确认窗口里双方已经贴身演完反制，不再用 Ground 处决的距离门卡住。
    if (kind == FinisherKind.Ground)
    {
        float dist = Vector3.Distance(
            initiator.transform.position, victim.transform.position);
        if (dist > finisherRange) return false;
    }

    // 动画与距离校验通过后再对齐并锁定双方，避免失败请求残留演出状态。
    AlignFinisherFacing(initiator, victim, playerAnim, bossAnim);

    active = new PairedPerformance { Initiator = initiator, Victim = victim };

    initiator.ActiveAttack = null;
    initiator.MoveDirection = Vector3.zero;
    victim.MoveDirection = Vector3.zero;
    initiator.IsFinisherLocked = true;
    victim.IsFinisherLocked = true;
    initiator.KengekiArmed = false;
    victim.KengekiArmed = false;

    initiator.DisableWeaponHit();
    victim.DisableWeaponHit();
    CombatEventBus.TriggerFinisherOpportunityChanged(victim, false);

    // 双方分别进入配套叶子状态，结算和统一解锁由发起方动画结束驱动。
    victim.EnterGrounded(new FinisherVictimState(victim, bossAnim),
        "duel: finisher victim");
    initiator.EnterGrounded(new FinisherState(initiator, victim, playerAnim),
        "duel: finisher initiator");

    CombatEventBus.TriggerFinisherStarted(
        victim.transform.position, initiator, victim, kind);
    CombatEventBus.TriggerCameraShake(1f);
    return true;
}

// 按当前崩解来源选忍杀类型。连招窗口里再按攻击也走这里，优先于 NextCombo。
public bool TryExecuteAvailableFinisher(CharacterBody initiator)
{
    CharacterBody victim = FindAnyBrokenOpponent(initiator);
    if (victim == null) return false;

    return TryExecuteFinisher(
        initiator,
        FinisherKindFor(victim.CurrentPostureBreakSource));
}

// 动画结束由 FinisherState 调用；若 Clip 仍残留事件也不会重复清命。
public void ExecuteFinisher(CharacterBody source)
{
    if (source == null || active == null || source != active.Initiator) return;
    if (active.Victim == null || active.Resolved) return;

    active.Resolved = true;
    active.Victim.ClearLife();
    CombatEventBus.TriggerFinisherOpportunityChanged(active.Victim, false);
}

// 清除演出记录并恢复存活双方的操作与地面状态，最终败北的受方保持锁定。
public void CompleteFinisherSequence(CharacterBody player)
{
    if (player == null || active == null || player != active.Initiator) return;

    CharacterBody victim = active.Victim;
    active = null;

    player.IsFinisherLocked = false;
    if (victim != null && victim.LivesRemaining > 0)
        victim.IsFinisherLocked = false;

    CombatEventBus.TriggerFinisherEnded(player, victim);

    if (victim != null)
    {
        victim.ClearCombatYawFrozen();
        victim.SetSuppressRootYaw(false);
    }

    if (victim != null && victim.LivesRemaining > 0)
        victim.EnterGrounded("duel: finisher sequence complete");

    player.EnterGrounded("duel: finisher sequence complete");
}
```

### 3.4 `FinisherState` 与 `FinisherVictimState` 生命周期及真实源码

- **继承与重写关系**：
  - `FinisherState` 与 `FinisherVictimState` 均直接继承自 `BaseState`，且均完整重写了 `OnEnter()`、`OnExit()`、`OnUpdate()`、`HandleCommand(ICommand cmd)`、`OnHitReceived(HitData hit)` 五个虚方法。
- **单主控退出契约**：
  - 受害方 `FinisherVictimState` 既用于弹反/识破打崩后的确认窗口（播放 `Stagger_Broken_Deflect` / `Stagger_Broken_Mikiri`），也用于正式成对忍杀演出（播放 `Finsher_*`）。它在 `OnUpdate()` 中绝不自行计时退出：确认窗口阶段由玩家侧的 `FinisherReadyState` / `MikiriCounterState` 负责超时恢复，成对演出阶段则完全由玩家侧的 `FinisherState.OnUpdate()` 在 `normalizedTime >= 0.98f` 时调用 `ExecuteFinisher` 与 `CompleteFinisherSequence` 统一解锁释放双方，杜绝双方因动画 Clip 帧长微小差异而提前脱锁。

```csharp
// 玩家成对忍杀状态：动画播完后代码结算清命并解锁双方，不依赖命中帧事件。
// CombatManager 安排双方进入各自状态；玩家这一侧负责报告忍杀结束，受害方不自行退出。
public class FinisherState : BaseState
{
    private readonly CharacterBody victim;
    private readonly string animName;
    private bool hasSeenAnim;
    private bool hasCompleted;

    public FinisherState(
        CharacterBody body,
        CharacterBody victim,
        string animName) : base(body)
    {
        this.victim = victim;
        this.animName = animName;
    }

    public override void OnEnter()
    {
        hasSeenAnim = false;
        hasCompleted = false;
        body.IsFinisherLocked = true;
        body.AttackUninterruptible = false;
        body.MoveDirection = Vector3.zero;
        body.DisableWeaponHit();
        Vector3 v = body.Rb.velocity;
        body.Rb.velocity = new Vector3(0f, v.y, 0f);

        if (victim != null)
        {
            Vector3 toVictim = victim.transform.position - body.transform.position;
            body.SnapYaw(toVictim, animName);
        }

        if (!AnimUtil.TryPlay(body.Animator, animName))
        {
            Debug.LogError($"{body.name} 的 Animator 缺少忍杀状态：{animName}");
        }
    }

    public override void OnExit()
    {
        body.IsFinisherLocked = false;
    }

    public override void OnUpdate()
    {
        if (hasCompleted) return;

        body.MoveDirection = Vector3.zero;

        AnimatorStateInfo info = body.Animator.GetCurrentAnimatorStateInfo(0);
        if (AnimUtil.IsPlaying(info, animName))
        {
            hasSeenAnim = true;
            if (info.normalizedTime < 0.98f) return;
        }
        else
        {
            if (!hasSeenAnim || body.Animator.IsInTransition(0)) return;
        }

        hasCompleted = true;
        // 先记完成再通知流程，避免后续更新重复扣命；先结算，再让流程统一释放双方。
        CombatManager.Instance.ExecuteFinisher(body);
        CombatManager.Instance.CompleteFinisherSequence(body);
    }

    // 处决期间吞掉所有命令（不可打断）
    public override bool HandleCommand(ICommand cmd)
    {
        return true;
    }

    public override bool OnHitReceived(HitData hit)
    {
        return true;
    }
}
```

```csharp
// Boss 在忍杀确认窗口或成对忍杀演出中的锁定状态。
// 不自行超时：确认窗口由玩家状态负责，演出结束由 CombatManager 统一释放。
public class FinisherVictimState : BaseState
{
    private readonly string animName;
    private bool triedNestedPath;
    private float timer;

    public FinisherVictimState(CharacterBody body, string animName) : base(body)
    {
        this.animName = animName;
    }

    public override void OnEnter()
    {
        triedNestedPath = false;
        timer = 0f;
        body.IsFinisherLocked = true;
        body.AttackUninterruptible = false;
        body.MoveDirection = Vector3.zero;
        body.DisableWeaponHit();
        Vector3 v = body.Rb.velocity;
        body.Rb.velocity = new Vector3(0f, v.y, 0f);

        // 成对忍杀开演才水平对视。确认窗口钉住被打断时的朝向。
        if (IsPairedFinisherAnim(animName))
        {
            body.ClearCombatYawFrozen();
            Vector3 toPlayer =
                CombatManager.Instance.PlayerRef.transform.position - body.transform.position;
            body.SnapYaw(toPlayer, animName);
        }
        else
        {
            body.FreezeCombatYaw();
        }

        if (!AnimUtil.TryPlay(body.Animator, animName))
        {
            Debug.LogError($"{body.name} 的 Animator 缺少忍杀受害状态：{animName}");
        }
    }

    public override void OnExit()
    {
        body.IsFinisherLocked = false;
    }

    public override void OnUpdate()
    {
        // 仅保持静止并补试动画请求，不在这里自行计时解锁；双方必须由同一流程统一退出。
        body.MoveDirection = Vector3.zero;
        if (triedNestedPath) return;

        timer += Time.deltaTime;
        AnimatorStateInfo info = body.Animator.GetCurrentAnimatorStateInfo(0);
        if (AnimUtil.IsPlaying(info, animName))
        {
            triedNestedPath = true;
            return;
        }

        if (timer <= 0.05f) return;

        triedNestedPath = true;
        AnimUtil.TryPlay(body.Animator, animName);
    }

    public override bool HandleCommand(ICommand cmd)
    {
        return true;
    }

    public override bool OnHitReceived(HitData hit)
    {
        // 成对动作中的伤害/清命由流程结算，不能让普通武器命中打断或重复结算。
        return true;
    }

    // 资源名是 Finsher_*（缺字母 i）；Miriki 拼写也走这个前缀。
    private static bool IsPairedFinisherAnim(string name)
    {
        return !string.IsNullOrEmpty(name) && name.StartsWith("Finsher_");
    }
}
```

### 3.5 `CombatStats.ClearLife` 处决扣命与胜负结算真实源码

```csharp
// 处决清一条命：扣命 → 没命了发胜利事件；还有命 → 重置架势回满血接着打
public void ClearLife()
{
    // HP 归零后的回生次数与忍杀扣除的命数是两套数据；这里扣 LivesRemaining。
    LivesRemaining--;
    CurrentPosture = 0f;
    IsPostureBroken = false;
    ResetConsecutiveTimesParried();
    CombatEventBus.TriggerFinisherOpportunityChanged(body, false);

    CombatEventBus.TriggerLifeCleared(body, LivesRemaining);

    if (LivesRemaining <= 0)
    {
        body.AttackUninterruptible = false;
        body.DisableWeaponHit();
        body.MoveDirection = Vector3.zero;
        CombatEventBus.TriggerVictory(body);
        return;
    }
    CharacterConfig config = body.Config;
    CurrentHP = config.MaxHP;
    CombatEventBus.TriggerPostureChanged(body, 0f, config.MaxPosture);
    CombatEventBus.TriggerHPChanged(body, CurrentHP, config.MaxHP);
}
```

## 4. 死亡、回生与战斗生命周期重置（DeadState → EncounterScope & ICombatResettable）

项目中严格区分了**两套生命机制**：
- **Boss 的管数（`LivesRemaining`）**：只能通过忍杀处决调用 `CombatStats.ClearLife()` 扣除。当 Boss 的 `CurrentHP` 被普通攻击打空时，Boss 架势恢复极慢、极易被打崩处决，但不会直接走 `GameOverState`。当忍杀使 Boss 的 `LivesRemaining <= 0` 时，广播 `CombatEventBus.TriggerVictory(body)`，且 `DuelDirector.CompleteFinisherSequence` 不再将 Boss 切回 `GroundedState`，使败北的 Boss 保持 `IsFinisherLocked = true` 留在处决终结姿态。
- **玩家的回生次数（`ReviveRemaining`）**：当玩家 `CurrentHP <= 0` 时，`CombatStats.TakeDamage` 触发 `HandleDeath()`，根据 `ReviveRemaining > 0` 回调 `CharacterBody.EnterDead(canRevive)`，切入顶层父状态 `DeadState`。

### 4.1 玩家死亡、回生与两种重置方式完整调用树

```text
[触发路径：玩家 HP 归零进入死亡父状态]
CharacterBody.ReceiveHit(...)
  └── CharacterBody.TakeDamage(healthDmg, postureDmg, attacker)
        └── CombatStats.TakeDamage(healthDmg, postureDmg, instigator)
              └── [CurrentHP <= 0] CombatStats.HandleDeath()
                    ├── [ReviveRemaining > 0]
                    │     ├── CombatEventBus.TriggerReviveAvailable(body)
                    │     └── onDeath(true) ──► CharacterBody.EnterDead(canRevive: true)
                    │           └── MainStateMachine.ChangeState(new DeadState(this, canRevive: true))
                    │                 └── DeadState.GetInitialSubState() ──► new RevivePendingState(body, this)
                    └── [ReviveRemaining <= 0]
                          ├── CombatEventBus.TriggerDeath(body)
                          └── onDeath(false) ──► CharacterBody.EnterDead(canRevive: false)

        │           └── 播放 "Revive" 动画，满 reviveDuration (1.5s) 后：
        │                 ├── body.SetReviving(false)
        │                 └── body.EnterGrounded("revive: animation finished")
        └── [按防御键：cmd is DeflectCommand]
              └── GiveUp()
                    ├── CombatEventBus.TriggerDeath(body)
                    └── body.EnterDead(canRevive: false, alreadyDowned: true, reason: "revive: give up")
                          └── 进入 GameOverState(alreadyDowned: true) [直接维持 "Deading" 躺地动画]

[分支 B：真死后按攻击键重载整个 Unity 场景（重量级重置）]
GameOverState.HandleCommand(AttackCommand)
  └── SceneManager.LoadScene(SceneManager.GetActiveScene().buildIndex)

[分支 C：不重载场景的场内快速复位（EncounterScope + ICombatResettable）]
EncounterResetDebug.Update() [按下 F8 热键]（或连战/复战流程调用）
  └── EncounterScope.Current.ResetAll()
        └── 倒序遍历 resettable 列表，剔除已销毁对象（IsGone），逐一调用 item.ResetForEncounter()：
              ├── 1. CharacterBody.ResetForEncounter() [玩家与 Boss]
              │     ├── Combat.ResetForEncounter() [HP/架势/葫芦/回生/命数全部从 CharacterConfig 恢复初始值]
              │     ├── 清空战斗标志（IsKnockedDown / IsGuarding / IsHealing / AttackUninterruptible / IsFinisherLocked / IsParried / KengekiArmed / IsReviving）
              │     ├── 清空出招与武器残留（ActiveHitPulseIndex = -1 / ActiveAttack = null / DisableWeaponHit()）
              │     ├── 清空连弹计数与弹反空按记忆（ResetConsecutiveTimesParried / ResetDeflectAttempts）
              │     ├── 还原初始站位与刚体速度（SetPositionAndRotation(spawnPosition, spawnRotation) + Physics.SyncTransforms()）
              │     ├── 状态机切回地面待机（EnterGrounded("encounter reset: grounded idle")）
              │     └── 广播初始数值同步 UI（TriggerHPChanged / TriggerPostureChanged / TriggerFinisherOpportunityChanged）
              ├── 2. CombatManager.ResetForEncounter()
              │     ├── TimeScaleController.CancelHitStop() [清除残留顿帧]
              │     └── director.Configure(ActiveBoss) + director.ResetForEncounter()
              ├── 3. DuelDirector.ResetForEncounter()
              │     └── 若 active != null，解除双方 IsFinisherLocked 并置 active = null
              ├── 4. ArrowProjectile.ResetForEncounter() [销毁飞行中的残留箭矢]
              └── 5. CombatUIController / BossVoiceDirector.ResetForEncounter() [重置 HUD 视图与台词状态]
```

### 4.2 `DeadState`、`RevivePendingState` 与 `GameOverState` 生命周期及真实源码

- **继承与重写关系**：
  - `DeadState` 继承自 `HierarchicalState`。重写了 `GetInitialSubState()`、`OnParentHandleCommand(ICommand cmd)`（返回 `false` 放行给子状态处理按键）、`OnParentHandleHit(HitData hit)`（返回 `true` 拦截一切受击）；`OnEnter()`、`OnUpdate()`、`OnExit()` 直接继承 `HierarchicalState` 的父子级联实现。
  - `RevivePendingState` 继承自 `BaseState`。重写了 `OnEnter()`、`OnUpdate()`、`HandleCommand(ICommand cmd)`、`OnExit()`；未重写 `OnHitReceived`（已被父状态 `DeadState.OnParentHandleHit` 拦截）。
  - `GameOverState` 继承自 `BaseState`。重写了 `OnEnter()`、`OnUpdate()`、`HandleCommand(ICommand cmd)`；未重写 `OnExit()` 与 `OnHitReceived`。

```csharp
// 死亡父状态：可回生时进入选择待机，否则进入游戏结束并允许攻击键重载场景。
// HP 归零时由 CombatStats 回调 CharacterBody 进入；数值结算已经完成，本层只选死亡流程。
public class DeadState : HierarchicalState
{
    private readonly bool canRevive;
    private readonly bool alreadyDowned; // 放弃回生时已经躺着，真死不再重播倒地。

    public DeadState(CharacterBody body, bool canRevive, bool alreadyDowned = false) : base(body)
    {
        this.canRevive = canRevive;
        this.alreadyDowned = alreadyDowned;
    }

    protected override BaseState GetInitialSubState()
    {
        return canRevive
            ? new RevivePendingState(body, this)
            : (BaseState)new GameOverState(body, this, alreadyDowned);
    }

    // 死亡期间命令放行给子状态（复活/重开按键由子状态处理并吞掉其余命令）
    protected override bool OnParentHandleCommand(ICommand cmd)
    {
        return false;
    }

    // 死亡期间无视所有受击
    protected override bool OnParentHandleHit(HitData hit)
    {
        return true;
    }
}
```

```csharp
// 倒地后等待回生选择，阶段计时结束才开放输入，选择等待不超时。
// 攻击键回生并播放起身，防御键放弃回生进入真死。
public class RevivePendingState : BaseState
{
    private HierarchicalState parent;
    private float fallTimer;
    private float fallDuration = 1.2f;
    private float reviveTimer;
    private float reviveDuration = 1.5f;
    private bool lying;
    // choiceReady 区分“倒地动画还没结束”和“可以选择回生”；reviving 区分已选择后的起身过程。
    private bool reviving;
    private bool choiceReady;

    public RevivePendingState(CharacterBody body, HierarchicalState parent) : base(body)
    {
        this.parent = parent;
    }

    public override void OnEnter()
    {
        fallTimer = 0f;
        reviveTimer = 0f;
        lying = false;
        reviving = false;
        choiceReady = false;
        AnimUtil.TryCrossFade(body.Animator, "Dead", 0.1f);
    }

    public override void OnUpdate()
    {
        if (reviving)
        {
            reviveTimer += Time.deltaTime;
            if (reviveTimer >= reviveDuration)
            {
                body.SetReviving(false);
                body.EnterGrounded("revive: animation finished");
            }
            return;
        }

        if (!choiceReady)
            fallTimer += Time.deltaTime;

        if (!lying && IsFallFinished())
        {
            lying = true;
            AnimUtil.TryCrossFade(body.Animator, "Deading", 0.05f);
        }

        // 等倒地时长走完再开选项，避免动画提前结束时变暗期间就能按键
        if (lying && !choiceReady && fallTimer >= fallDuration)
        {
            choiceReady = true;
            CombatEventBus.TriggerReviveChoiceReady(body);
        }
    }

    public override bool HandleCommand(ICommand cmd)
    {
        if (reviving || !choiceReady) return true;

        if (cmd is AttackCommand)
        {
            BeginRevive();
            return true;
        }

        if (cmd is DeflectCommand)
        {
            GiveUp();
            return true;
        }

        return true;
    }

    private void BeginRevive()
    {
        // 选择时立即回满 HP 并扣回生次数，但起身动画期间仍置 IsReviving，AI 不应把人当作已恢复操作。
        body.SetReviving(true);
        body.Revive();
        reviving = true;
        reviveTimer = 0f;
        AnimUtil.TryCrossFade(body.Animator, "Revive", 0.1f);
    }

    public override void OnExit()
    {
        body.SetReviving(false);
    }

    private void GiveUp()
    {
        // 选择等待本身不超时；只有主动放弃才从可回生分支切到真死分支。
        CombatEventBus.TriggerDeath(body);
        body.EnterDead(false, alreadyDowned: true, reason: "revive: give up");
    }

    private bool IsFallFinished()
    {
        var info = body.Animator.GetCurrentAnimatorStateInfo(0);
        if (AnimUtil.IsPlaying(info, "Dead") && info.normalizedTime >= 0.95f) return true;
        return fallTimer >= fallDuration;
    }
}
```

```csharp
// 游戏结束：真死。未倒地则先 Dead 再 Deading；已躺着则直接 Deading。
// 按攻击键重开当前场景
public class GameOverState : BaseState
{
    private HierarchicalState parent;
    private readonly bool alreadyDowned;
    private float fallTimer;
    private float fallDuration = 1.2f;
    private bool lying;

    public GameOverState(CharacterBody body, HierarchicalState parent, bool alreadyDowned = false) : base(body)
    {
        this.parent = parent;
        this.alreadyDowned = alreadyDowned;
    }

    public override void OnEnter()
    {
        fallTimer = 0f;
        if (alreadyDowned)
        {
            lying = true;
            AnimUtil.TryCrossFade(body.Animator, "Deading", 0.05f);
        }
        else
        {
            lying = false;
            AnimUtil.TryCrossFade(body.Animator, "Dead", 0.1f);
        }
    }

    public override void OnUpdate()
    {
        if (lying) return;

        fallTimer += Time.deltaTime;
        var info = body.Animator.GetCurrentAnimatorStateInfo(0);
        if ((AnimUtil.IsPlaying(info, "Dead") && info.normalizedTime >= 0.95f) || fallTimer >= fallDuration)
        {
            lying = true;
            AnimUtil.TryCrossFade(body.Animator, "Deading", 0.05f);
        }
    }

    public override bool HandleCommand(ICommand cmd)
    {
        if (cmd is AttackCommand)
        {
            // 同一个 AttackCommand 在不同状态有不同含义：真死分支用它重载当前场景。
            SceneManager.LoadScene(SceneManager.GetActiveScene().buildIndex);
            return true;
        }
        return true;
    }
}
```

### 4.3 场内快速重置（`EncounterScope` + `ICombatResettable`）与场景重载的区分

| 对比维度 | 场景重载（`SceneManager.LoadScene`） | 场内快速重置（`EncounterScope.ResetAll`） |
| :--- | :--- | :--- |
| **触发入口** | `GameOverState.HandleCommand(AttackCommand)` | `EncounterResetDebug`（`F8` 热键）或复战流程调用 `EncounterScope.Current.ResetAll()` |
| **开销与耗时** | 销毁整棵场景 Hierarchy、重新反序列化场景资产、重新执行所有 `Awake` / `Start` | 零场景卸载与反序列化开销，原地恢复数值、站位、状态机与 UI |
| **无序独立性契约** | 由 Unity 场景加载生命周期重建 | 各组件实现 `ICombatResettable.ResetForEncounter()`，只复位自身状态并主动发事件，不依赖其他组件的复位先后顺序 |
| **Unity 假非空清理** | 不涉及 | `EncounterScope.IsGone(target)` 显式转型 `target is Object unityObj && unityObj == null`，识别并剔除已在战斗中 `Destroy` 的 `MonoBehaviour`（如已销毁的箭矢） |

```csharp
// 供 EncounterScope 统一复位本场临时状态；各实现应可重复调用，且不依赖其他组件的复位顺序。
// 通常恢复自身初始值，运行时生成的箭矢等对象则自行销毁。
public interface ICombatResettable
{
    void ResetForEncounter();
}
```

```csharp
// EncounterScope.cs 核心登记与复位逻辑
// 登记复位能力，不要求组件按某个固定顺序完成 Start；重复登记同一对象会被忽略。
public void Register(ICombatResettable target)
{
    if (target == null) return;
    if (!resettable.Contains(target))
        resettable.Add(target);
}

public void Unregister(ICombatResettable target)
{
    if (target == null) return;
    resettable.Remove(target);
}

// 各组件自行复位且不得依赖调用顺序；倒序仅用于安全移除已销毁的登记项。
public void ResetAll()
{
    for (int i = resettable.Count - 1; i >= 0; i--)
    {
        ICombatResettable item = resettable[i];
        if (IsGone(item))
        {
            resettable.RemoveAt(i);
            continue;
        }
        item.ResetForEncounter();
    }
}

// 接口引用上的 == 不会触发 UnityEngine.Object 的销毁判定，
// 已销毁的 MonoBehaviour 会以"假非空"形式留在表里，必须显式识别。
static bool IsGone(ICombatResettable target)
{
    if (target == null) 
        return true;
    return target is Object unityObj && unityObj == null;
}
```

```csharp
// CharacterBody.cs：不重载场景地恢复角色数值、战斗标志、初始站位和地面待机状态。
public void ResetForEncounter()
{
    // 1. 数值：HP / 架势 / 葫芦 / 复活次数 / 命数
    Combat.ResetForEncounter();

    // 清除战斗锁，避免上一场的受击或成对演出阻断新一场操作。
    IsKnockedDown = false;
    IsGuarding = false;
    IsHealing = false;
    AttackUninterruptible = false;
    IsAttackRecoveryOpen = false;
    IsFinisherLocked = false;
    IsParried = false;
    KengekiArmed = false;
    SetReviving(false);
    ClearPlayerParryAttackWindow();

    // 3. 出招残留：出招途中被打断重开，会带着上一刀的判定数据
    ActiveHitPulseIndex = -1;
    ActiveAttack = null;
    CurrentMoveEntry = null;
    CurrentMoveWindow = null;
    DisableWeaponHit();

    // 4. 连弹计数：JumpThrust 的抽招条件，跨场累积会让复战开局就放出不该放的招
    ResetConsecutiveTimesParried();
    ResetAirJump2();

    // 弹反窗口与空按惩罚不跨场保留。
    ResetDeflectAttempts();

    // 5. 朝向锁定
    ClearCombatYawFrozen();
    SetSuppressRootYaw(false);

    // 6. 位移：不清的话刚体会带着上一场的速度继续滑出去
    MoveDirection = Vector3.zero;
    PreferFastWalk = false;
    Rb.velocity = Vector3.zero;
    Rb.angularVelocity = Vector3.zero;

    // 7. 站位与朝向复位。流程层若要把角色放到别处，在 ResetAll() 之后覆盖即可。
    transform.SetPositionAndRotation(spawnPosition, spawnRotation);
    Physics.SyncTransforms();

    // 8. 状态机回地面待机
    EnterGrounded("encounter reset: grounded idle");

    // 复位绕过伤害结算，需主动发事件让 UI 同步初始数值。
    CombatEventBus.TriggerHPChanged(this, CurrentHP, Config.MaxHP);
    CombatEventBus.TriggerPostureChanged(this, CurrentPosture, Config.MaxPosture);
    CombatEventBus.TriggerFinisherOpportunityChanged(this, false);
}
```
