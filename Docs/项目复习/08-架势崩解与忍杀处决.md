# 架势崩解与忍杀处决

这一篇回答：架势条满以后，系统如何从普通战斗切换到双方同步的忍杀演出。

## 1. 架势如何累计

`CombatStats.AccumulatePosture` 是统一入口。架势来源包括：

- 普通攻击命中。
- 普通格挡承受对方架势伤害。
- 完美弹反给攻击者增加架势。
- 识破给突刺攻击者增加大量架势。
- 双方 Hitbox 拼刀。

每次变化都会发布架势事件，UI 据此更新架势条。

## 2. 架势恢复

停止受击超过 `PostureDecayDelay` 后，架势按配置速度恢复。

- 玩家可以按住格挡提高恢复倍率。
- Boss 可使用非线性恢复：架势越高，恢复越慢。
- 崩解状态中不再自然恢复。

## 3. 架势崩解

架势达到最大值时：

```text
IsPostureBroken = true
→ 记录 PostureBreakSource
→ 发布 PostureBroken
→ 发布 FinisherOpportunityChanged(true)
→ CharacterBody.ForcePostureBroken
```

玩家崩解主要进入击飞或倒地恢复流程；Boss 崩解则形成忍杀窗口。

崩解来源分为：

- `Attack`
- `Deflect`
- `Mikiri`

它不仅用于统计，还决定使用哪组成对忍杀动画。

## 4. 玩家如何触发忍杀

Boss 崩解后，玩家再次发出 `AttackCommand`。`GroundedState` 在把攻击交给 Idle、Move 或 Attack 之前，优先调用：

```text
CombatManager.TryExecuteAvailableFinisher
→ DuelDirector 查找已崩解目标
→ 根据崩解来源选择 FinisherKind
→ 校验距离、动画和演出互斥
```

因此忍杀不是“崩解瞬间自动执行”，而是产生一个可由玩家确认的处决机会。

## 5. 为什么需要 DuelDirector

忍杀同时改变两个角色：

- 玩家进入 `FinisherState`。
- Boss 进入 `FinisherVictimState`。
- 双方移动清零并锁定输入、受击和普通 AI。
- 双方对齐朝向。
- 播放相互匹配的成对动画。

单个角色状态无法可靠管理“双方必须一起开始和结束”的场景级状态，因此由 `DuelDirector` 编排。

## 6. 忍杀结算

处决动画到达结算点后：

```text
DuelDirector.ExecuteFinisher
→ victim.ClearLife()
→ Boss LivesRemaining - 1
```

还有命：

- 清空架势和崩解标记。
- Boss 生命回满。
- 双方解除处决锁。
- 返回地面状态继续战斗。

没有命：

- 停止 Boss 攻击和武器判定。
- 发布 Victory。
- Boss 保持被击败状态，战斗结束。

## 7. 三类忍杀

- Ground：普通攻击造成的崩解，需要检查处决距离。
- Deflect：弹反造成的崩解，双方已经贴近，不再重复卡普通距离。
- Mikiri：识破造成的崩解，使用识破对应的成对动画。

## 8. 当前多命系统的边界

`LifeCount` 支持 Boss 多条命，但 `LivesRemaining` 当前没有直接切换另一套行为树或招式池。因此可以说“支持多条命并在处决后继续战斗”，不能说“实现了完整的二阶段 AI”。

## 9. 代价

- 成对动画要求双方 Animator 状态和 Root Motion 能对齐。
- 演出过程中任何异常退出都可能留下锁定，所以复战必须清理活动演出。
- 处决属于场景级事务，不能只看玩家或 Boss 单方状态。

## 面试追问梯度

### 基础概念

1. 生命值、架势值和命数分别表达什么？
2. 为什么架势崩解不等于立即死亡？

### 项目实现

3. `PostureBreakSource` 为什么会影响忍杀类型？
4. AttackCommand 为什么在 GroundedState 先检查忍杀，再下钻到 AttackState？
5. DuelDirector 怎样保证双方演出互斥和同步？

### 方案取舍

6. 为什么忍杀必须由场景级编排器管理？
7. 为什么 Ground 忍杀检查距离，而 Deflect/Mikiri 不重复检查？
8. 为什么处决结算使用命数，而不是直接把 HP 设为零？

### 扩展设计

9. 如果加入多 Boss，怎样选择被处决目标并避免同时处决？
10. 如果双方动画长度不同，结束条件怎样设计？
11. 如果真正实现二阶段 AI，应该由哪个事件驱动阶段切换？

### 故障排查

12. UI 出现红点但攻击没有进入忍杀，应检查哪些资格？
13. 处决结束后角色永久不能输入，最可能残留哪个锁定？

回答时把忍杀描述成“跨两个角色的事务”：资格校验、双方锁定、成对状态、清命结算、统一解锁。
