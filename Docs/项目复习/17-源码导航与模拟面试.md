## 2. 30 分钟模拟面试

### 0—2 分钟：介绍项目

问题：只用两分钟介绍最值得追问的三个点。

合格要点：个人单 Boss 战 Demo；玩家/AI 共用执行层；判定与响应分离；SO 与工具帮助配置；说清本人实际职责。避免连续报十几个系统名却没有一个具体问题。

### 2—7 分钟：从输入追到状态

问题：玩家提前按攻击为什么能接上下一刀？如果又按闪避呢？为什么 struct 仍有 GC？

合格要点：普通攻击松手产生意图、单槽覆盖、拒收重试、消费与超时；返回 true 不必然切状态；接口转换装箱及持续移动入口。加分：指出先消费后扣时、游戏时间与真实时间的区别。

### 7—12 分钟：从漏判追到数值

问题：刀穿过敌人却不掉血，你怎么排查？改 NonAlloc 是否就解决了？

合格要点：先分输入、状态、窗口、空间、去重、响应和 UI；知道 SphereCastAll 起始重叠的特殊返回、静止帧点检与旋转轨迹边界；知道 16 项缓冲的饱和风险。加分：说明命中不等于扣血，给出一项受控实验。

### 12—17 分钟：行为树与算法

问题：Running 节点是否一直续跑？权重 1、3 的两招中一招冷却，如何改变概率？

合格要点：当前 Selector 只锁实现 ISelectorLock 的直接子节点；普通追击允许重新评估；先过滤后加权；全部不可选返回 null；距离限制只在 Active 分支。加分：指出锁定期间优先级抢占边界、候选内部检查对复杂度的影响。

### 17—22 分钟：生命周期与工程

问题：第二局音效重复、AI 不动，你先查哪里？接口非空为何仍报对象已销毁？

合格要点：事件重复订阅/退订、旧协程和门禁、重置顺序假设；Unity 对象包装层与引擎生命周期；`EncounterScope.IsGone` 的具体判断。加分：区分可重复复位和“倒序调用天然正确”，展示一次复战记录。

### 22—27 分钟：性能和基础

问题：你做过什么优化？没有做过呢？

合格要点：有实测则交代设备、后端、场景、原始采样和同条件对照；没有则明确“目前是源码假设”，演示如何查调用栈。再抽一题：HashSet 复杂度、向量投影、Canvas 更新或 CPU/GPU 瓶颈区分。不会的点记录后补，不用不存在的经历填空。

### 27—30 分钟：个人贡献与改进

问题：AI 辅助生成后，你独立解决了什么？再给一周你先做什么？

合格要点：拿一个本人能证明的决策，讲问题、替代方案、选择、验证；下一步对应已观察到的缺口，不泛泛回答“上 ECS”。没有历史记录时可展示现在独立完成的小练习。

## 3. 现场手写与修改设计

以下是独立练习，不要求直接改主工程。先写输入输出和边界，再写最小实现。

1. **15 分钟，单槽输入缓冲**：支持覆盖、消费、拒收与超时，明确计时单位及临界帧顺序；手推三条时间线。
2. **15 分钟，加权选择**：过滤无效项后抽样；解释零权重、空集合、浮点边界与复杂度。测试随机分布须多次采样，不能要求少量随机样本严格等于理论比例。
3. **10 分钟，线段最近点**：解释投影、Clamp 与退化线段；用端点外侧和线段中部各验一个例子。
4. **15 分钟，复位设计**：设计拥有计时器、对象引用和事件订阅的组件，说明连续复位两次、对象被销毁、禁用再启用如何处理。
5. **15 分钟，Editor 操作说明**：在临时资产上设计一项带 Undo 的配置修改，解释记录修改、标记脏、持久化及 SerializedProperty 的分工。

通过标准：能独立写/画核心部分，解释至少两个边界，发现问题后能修正；不以“和仓库代码长得一样”为标准。

## 4. 一次演示该展示什么？

- 第一段：玩家与 Boss 交战，展示格挡/弹反、命中与架势反馈。
- 第二段：识破或忍杀，说明触发条件与双角色状态协调。
- 第三段：回生/复战，强调旧状态清理；失败也应记录已知问题。
- 第四段：配置时间轴调整与校验，演示工具如何缩短调参反馈过程。

每段标明录制版本和操作。资源来源、代码职责与个人贡献分开说明；不要把第三方动画或插件能力写成自研成果。
