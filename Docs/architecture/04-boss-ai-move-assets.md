弦一郎 AI 招式资源对照表

填「Animator 状态名」。clip 文件名可空（有动画即可）。受击/崩解/忍杀 **沿用现有，不必填**。

交锋 **不区分左弹/右弹**，被弹开后共用一张还击表。

本需求不做：普攻 1-2-3-4 连段机、脱衣、巴流、雷。其余按原作能进树的招都列在下面（含空中五连、蓄力重箭、交锋射箭）。

`Kengeki_Slash` 是我们起的名字。原作「弹开后砍一刀」是五条片：**3050 / 3055 / 3065 / 3071 / 3076**。五条都有则抽中本招时均匀随机，不要只播 3050。

## 怎么填


| 列            | 含义                                     |
| ------------ | -------------------------------------- |
| 招式 ID        | 规格/行为树用的名字，不要改                         |
| 原作编号         | `sekiro-genichiro-ai.md` 里的动画 ID，方便对资源 |
| 用途           | 哪一层会抽到                                 |
| 必须           | 是 = 进树；否 = 没有就不进权重                     |
| Animator 状态名 | `boss.controller` 短名                   |
| 备注           | 映射说明                                   |
