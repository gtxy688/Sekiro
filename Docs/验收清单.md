## 一、前置准备

### 1. 编译
- 等 Unity 重导入 `PlayerInputActions`（自动重新生成 .cs），确认 **Console 无报错**

### 2. 场景接线
| 对象 | 要挂/拖的东西 |
|---|---|
| **CombatManager**（Mgr 物体上） | `BossRef` 拖 Boss（**处决/锁定依赖，必拖**） |
| **玩家** | 挂 `LockOnManager` |
| **玩家** | 挂 `Player Input` 组件：Actions=资产、**Auto-Switch ✓**、Default Scheme=**KeyboardMouse** |
| **Boss** | `CharacterBody.AttackSet` 拖招式数组（建议 3 招：普通连段 ×2 + 最后一招 **Perilous=Thrust 突刺**） |
| **Boss** | `BTBrain`：`PlayerBody` 拖玩家、`PlayerTarget` 拖玩家、`BowShotConfig` 可空 |
| **Main Camera** | 挂 `CameraShake` |
| **AudioManager 物体** | 挂 AudioManager（音效可后拖） |
| **BGM 物体** | 挂 `BGMManager`（BGM 可后拖） |

### 3. 动画状态配置（占位名，M8 接真动画前）
按上一条回复的两张表，在 player.controller / boss.controller 里建同名**空状态**（无状态也不会崩，只是动画不切）。攻击动画状态名 = 对应 `AttackConfig.AnimName`。

## 三、战斗模块验收

### M8 攻击出伤害
- 玩家攻击 → Boss 掉血 + 涨架势；攻击结束判定关闭（空挥无效）

### M4 弹反/格挡
- **长按 RMB（≥0.15s）** = 举刀格挡 → Boss 砍你**不掉血**只涨架势
- **短按 RMB（<0.15s）** = 甩刀弹反，0.3s 窗口内被砍 → **Boss 被弹开硬直 + 涨架势**，自己涨少量
- 0.5s 内连点 3 次 → 窗口 ×0.75（下限 0.1s），停 0.5s 恢复
- Boss 突刺危字 → 格挡/弹反**无效**（硬吃）

### M17 危字/识破/跳踩
- 危字出招 → UI 弹"危"字
- 突刺 + 垫步 → Mikiri 动画 + Boss 大架势
- 垫步 0.3s 内普通攻击打不中
- Boss 横扫危字（若配）+ 玩家空中 → 跳踩反制涨架势

### M9 架势
- 格挡按住 2s 后架势回复明显变快
- Boss 架势越高回越慢（非线性）
- 玩家架势满 → 倒地（不被处决）→ 架势清空
- Boss 架势满 → 崩解硬直 5s（红点）

### M10 处决
- Boss 崩解后走近按 LMB → 处决动画 → 清 1 命满血续战
- 处决 2 次 → 胜利事件（"胜利"文字）

### M16 葫芦
- 按 E → 喝药动画 + 回血，动画期间被打断（血已回、药已耗）

### M14 复活/死亡重开
- 有复活次数被打死 → 倒地 → **按 LMB 复活满血**；超时/没次数 → 真死 → 按 LMB **重开场景**

### M11 锁定
- 中键锁定（移动面朝 Boss 绕圈）、再按解锁、Boss 死自动解锁

### M7 Boss AI
- Boss 按距离自动追击/连段/射箭
- 你攻击时 Boss 短按防御尝试**弹反你**（成功你就被弹开）

## 五、受击动画接口（你要求的预留）

`CharacterConfig` 四个动画名字段 `HurtAnim_Normal / Heavy / Guard / Deflected`，**留空 = 回退普通受击动画**，填了就走对应动画（配 `AttackConfig.Knockback` > 0 触发 Heavy）。想区分就填名字，不想区分全留空即可。

## 六、常见坑速查

- **占位动画名**（Deflect_Guard、Drink_Gourd 等）没建 → CrossFade 静默失败，角色"站着不动但逻辑在跑"，属正常，建状态即可
- **处决不触发** → 检查 `CombatManager.BossRef` 拖没拖 + Boss 是否 `IsPostureBroken` + 距离 ≤ finisherRange(2m)
- **锁定无效** → 检查玩家挂 `LockOnManager` 没
- **松键还走** → 检查 Player Input 组件 Auto-Switch 勾没勾
- **攻击打不出伤害** → 检查武器 Hitbox 的 `targetLayers` 含对方 Hurtbox 层 + Hitbox 挂在武器骨骼上
