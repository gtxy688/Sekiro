# 验收清单

> 复刻只狼弦一郎 Boss 战 | 战斗闭环 + Boss AI + 表现层代码已全部完成
> 本清单 = 你要在 Unity 里干的事 + 逐条验收步骤。按顺序做，崩了/不对就把现象发我。

## 一、前置准备

### 1. 编译
- 等 Unity 重导入 `PlayerInputActions`（自动重新生成 .cs），确认 **Console 无报错**

### 2. 场景接线
| 对象 | 要挂/拖的东西 |
|---|---|
| **Combat HUD** | 打开 `GameScene` → 菜单 **Tools/战斗/生成战斗 HUD**（生成 Canvas + 血条/架势/葫芦，自动拖玩家/Boss） |
| **CombatManager**（Mgr 物体上） | `BossRef` 拖 Boss（**处决/锁定依赖，必拖**） |
| **玩家** | 挂 `LockOnManager` |
| **玩家 Hitbox** | 挂在**武器中央**（刃中段，随刀动），不要挂在角色根/手柄骨 |
| **Boss Hurtbox** | 碰撞体**包住身体**；过小则连招第二刀容易扫空 |
| **玩家** | 挂 `Player Input`：Actions=资产、**Auto-Switch ✓**、Default Scheme=`KeyboardMouse`、**Default Map=`Player`**（不要留 `<None>`） |
| **Boss** | `CharacterBody.AttackSet` 拖招式数组（建议 3 招：普通连段 ×2 + 最后一招 **Perilous=Thrust 突刺**） |
| **Boss** | `BTBrain`：`PlayerBody` 拖玩家、`PlayerTarget` 拖玩家、`BowShotConfig` 可空 |
| **Main Camera** | 挂 `CinemachineBrain`（Update Method=`Late Update`，Default Blend ≈ **0.6s EaseInOut**）+ `CameraShake` + **`CameraController`**（**Blend Time ≈ 0.6**） |
| **FreeLook** | Follow / Look At 用 `CameraFollowTarget`（不要拖玩家根）；三个 Rig Aim = **Hard Look At**；Body 阻尼 **0**；Binding = **World Space**；Heading 速度滤波 **0**；挂 `CinemachineOrbitInput`；**关掉** `CinemachineInputProvider` |
| **锁定相机** | Follow 也是 `CameraFollowTarget`（锁定时脚本给 yaw 朝 Boss），Look At = Boss。可直接 Play（运行时自动补）；调机位：菜单 **Tools/战斗/生成锁定相机** 后 Ctrl+S |
| **AudioManager 物体** | 挂 AudioManager（音效可后拖） |
| **BGM 物体** | 挂 `BGMManager`（BGM 可后拖） |

Player Input 若出现「Project-wide actions asset is not recommended…」：`Edit → Project Settings → Input System Package` 把 Project-wide Actions 清空，角色上的 Actions 继续用 `PlayerInputActions`。

### 3. 动画状态（同名状态，可放进 Sub-state Machine）

玩家 / Boss 用**同一套状态名**，各绑各的 Clip。攻击状态名 = 对应 `AttackConfig.AnimName`。没建不会崩，只是站着不动但逻辑在跑。

代码用短名 `CrossFade` / `shortNameHash` 查找，子状态机里只要**整层名字不重复**即可。

**双方共用**

| 状态名 | 用途 | Loop |
|--------|------|------|
| `Idle` | 待机 | 开 |
| `IdleToWalk` | 未锁定：待机起步（没有这个状态就直接 `Walk`，Boss 不用配） | 关 |
| `Walk` | 未锁定：向前走 | 开 |
| `Jump` / `Fall` | 起跳 / 下落 | 关 |
| `Hurt_Ground` | 普通受击 | 关 |
| `Hurt_Guard` | 格挡轻攻击 | 关 |
| `Hurt_GuardHeavy` | 格挡重攻击（该招 `AttackConfig.Knockback` > 0） | 关 |
| `Stagger_Broken` | 架势崩解倒地 | 关 |
| `Deflect_Begin` | 抬刀 | 关 |
| `Deflect_Guard` | 静止举刀 | 开 |
| `Deflect_Walk` | 未锁定举刀走 | 开 |
| `Deflect_Cancel` | 长按松手收刀 | 关 |
| `Deflect_Slash` | **挡住后**的弹反受击（不是松手甩刀） | 关 |

**只有玩家**

| 状态名 | 用途 | Loop |
|--------|------|------|
| `Dodge` | 未锁定垫步 | 关 |
| `DodgeToWalk` | 未锁定：垫步结束接走 | 关 |
| `Dodge_Forward` | 锁定：朝 Boss 垫 | 关 |
| `Dodge_Back` | 锁定：后垫（无方向也用这个） | 关 |
| `Dodge_Left` / `Dodge_Right` | 锁定：侧垫 | 关 |
| `IdleToStrafe` | 锁定：待机起步（2D 融合树，参数 `MoveX`/`MoveZ`） | 关 |
| `Walk_Strafe` | 锁定：四向循环走（同上融合树） | 开 |
| `Deflect_Strafe` | 锁定：举刀四向走（`MoveX`/`MoveZ`） | 开 |
| `Deflect_Repeat` | 格挡中再按（抖刀） | 关 |
| `Mikiri` | 识破 | 关 |
| `Drink` | 喝葫芦（不是 `Drink_Gourd`） | 关 |
| `Finisher` | 处决 | 关 |
| `Dead` | 倒地过程 | 关 |
| `Deading` | 躺地等待（回生或重开） | 开 |
| `Revive` | 爬起 | 关 |

**只有 Boss：** `Bow_Draw`（拉弓）。Boss Controller 也要有一套 `Deflect_*`（AI 会弹反）。

`Death` / `Death_Pending` / `Drink_Gourd` 已废弃。`Dead` 与 `Deading` 是两段：先倒下再躺着，超时真死**不再重播倒地**。

融合树摆法（角色空间，脸朝前 = +Z，右 = +X）：`(0,1)` 前、`(0,-1)` 后、`(-1,0)` 左、`(1,0)` 右。

锁定垫步**不要**做成融合树：四个一次性状态并排即可，代码 `CrossFade` 短名。斜向 WASD 取最近轴，不会播 45° 混合。

## 二、输入验收（M6 + 双方案）

| 操作 | 预期 |
|---|---|
| WASD | 未锁定：相对相机（W=屏幕里走），身体转向移动方向；松键立即停 |
| 中键锁定后 WASD | 身体朝 Boss；`IdleToStrafe` → `Walk_Strafe`；W 靠近、S 后退、A/D 侧移 |
| 锁定后 WASD + Shift | 四向垫步：W=`Dodge_Forward`、S=`Dodge_Back`、A=`Dodge_Left`、D=`Dodge_Right`；无方向只 Shift = 后垫；身体朝 Boss |
| LMB / RMB / Shift / Space / E / 中键 | 攻击/防御/垫步/跳/葫芦/锁定 各有响应 |
| 手柄推摇杆 | 自动切 Gamepad，走+松停 |
| 手柄游玩中按键盘 | 自动切回键鼠，两设备互不干扰 |

## 三、战斗模块验收

### M8 攻击出伤害
- 玩家攻击 → Boss 掉血 + 涨架势；**进攻击就开判定，退出攻击就关**（空挥出招结束后无效）
- 连招第二刀（Attack2）也要打中。若只有第一刀中、第二刀空：先查 **玩家 Hitbox 是否在武器中央**、**Boss Hurtbox 碰撞体是否包住身体**
- `HitStartTime` 只管前摇取消（时间内 RMB/Shift 能取消）；填 0 = 进招不能取消

### 取消（前摇 / 格挡连按）
- 挥刀**取消窗口内**（`HitStartTime`）按 RMB → 立刻抬刀格挡，这一刀打不出去
- 取消窗口内按 Shift → 立刻垫步，这一刀打不出去
- 过了取消窗口再按 RMB/Shift → 这一刀挥完；若在 0.2s 内挥完，落地会接上格挡/垫步
- 格挡中再按 RMB → 播 `Deflect_Repeat`（抖刀）、弹反窗口刷新（抬刀/举刀/弹刀成功/收刀都能再按）；没有该状态则回退 `Deflect_Begin`
- 格挡中按 Shift → 立刻垫步（含收刀、弹刀成功期间）
- 0.5s 内连点格挡 ≥3 次 → 弹反窗口 ×0.75（下限 0.1s），停 0.5s 恢复（抖刀）
- 垫步过程中按格挡/攻击 → 不打断垫步

### M4 弹反/格挡
短按 / 长按都是**格挡**。弹反不是一种按法，是 **0.3s 窗口内把刀接住**。

- 待机按下 → `Deflect_Begin` → 站着 `Deflect_Guard`；按住再 WASD → `Deflect_Walk`（锁定 → `Deflect_Strafe`）
- **走着按下** → 不播原地抬刀，约 0.22s 融到 `Deflect_Walk` / `Deflect_Strafe`（步伐接上、刀是抬起来的，不抽搐）
- **长按松手（≥0.15s）** → `Deflect_Cancel` 再回待机（收刀期间仍可再按格挡或垫步取消）
- **短按松手（<0.15s）** → 不播收刀，窗口结束回待机（窗口内仍可弹反）
- **窗口内挡住** → `Deflect_Slash` + Boss 被弹开硬直 + 涨 Boss 架势，自己涨少量且不崩防
- **窗口外仍按着挡住** → 不掉血只涨自己架势 + 普通格挡受击，仍按着则回到举刀
- Boss 突刺危字 → 格挡/弹反**无效**（硬吃）

### M17 危字/识破/跳踩
- 危字出招 → UI 弹"危"字
- 突刺 + 垫步 → Mikiri 动画 + Boss 大架势
- 垫步 0.3s 内普通攻击打不中
- Boss 横扫危字（若配）+ 玩家空中 → 跳踩反制涨架势

### M9 架势
- 格挡按住 2s 后架势回复明显变快
- Boss 架势越高回越慢（非线性）
- 玩家架势满 → 倒地（不被处决）→ 架势清空
- Boss 架势满 → 崩解硬直 5s（红点）

### M10 处决
- Boss 崩解后走近按 LMB → 处决动画 → 清 1 命满血续战
- 处决 2 次 → 胜利事件（"胜利"文字）

### M16 葫芦
- 按 E → `Drink` + 回血（满血也能喝，扣 1 次，HP 封顶）；动画期间被打断（血已回、药已耗）

### M14 复活/死亡重开
- 有次数被打死 → `Dead` 倒下 → `Deading` 躺地 → **按 LMB** 播 `Revive` 满血续战
- 超时 / 没次数 → 保持躺地（不重播倒地）→ 按 LMB **重开场景**

### M11 锁定
- 中键锁定 / 再按解锁；Boss 死自动解锁
- 锁定中走着再解锁 → 切回向前 `Walk`；未锁定走着再锁定 → 切 `Walk_Strafe`
- 锁定后镜头切第三人称跟随（看向 Boss）；解锁切回 FreeLook（详见 M12）
- 锁定点：`FocusOn` 钉在 Boss `Spine1`，Overlay 相机不被挡；崩解切 `Finsher`

### M7 Boss AI（简单版：先看手感）
- Boss 会追过来；进攻击距离后打 **一刀**，然后停约 2.5s 再打
- 你在近处挥刀 → Boss 短按格挡；窗口内砍中 → 弹反你
- 远距射箭 / 连段 / 交锋变招这版不做

### M12 相机（FreeLook + 锁定跟随）

- Binding Mode = **World Space**；Heading = **Position Delta**，Velocity Filter = **0**（2.10 没有 World Heading）；Recenter 关
- 场景根上 `CameraFollowTarget`：Source 拖玩家，Height≈1.4，**不要当玩家子物体**。FreeLook 的 **Follow 和 Look At 都拖它**（不要拖玩家根或骨骼）
- 三个 Rig：Aim = **Hard Look At**；Body X/Y/Z Damping = **0**（不要 0.1～0.2，那会走路发糊）
- 垂直轴不要把 FreeLook 的 Axis Speed 拉很高；用 `CinemachineOrbitInput` 的 `YSpeed` + 松手回中（`YCenter`≈0.45）
- **未锁定**：镜头独立转，角色朝镜头方向走；侧向走画面清晰、人居中（可有步伐起伏，不是拖影）
- **锁定（中键）**：约 0.6s 从当前机位滑到 `LockOn Camera`（Follow 仍是跟随点，Look At Boss）；不应硬切、穿地或突然变焦；角色面朝 Boss 围着走；鼠标不再 FreeLook 环绕
- **再按中键 / Boss 死**：镜头留在角色背后接着当 FreeLook，不回到锁定前的环绕角
- **锁定贴墙**：镜头应收到墙外；墙没碰撞体则避不了（换地图或给墙加 MeshCollider）
- 切镜手感：Main Camera 上 `CameraController.Blend Time`（默认 0.6；更快 0.45，更软 0.8）
- 玩家 `Animator.applyRootMotion` 勾选（相机跟点，不关根运动）
- 不要靠调大 DeadZone 防抖；不要给跟随点加位置平滑

## 四、表现层验收（先验血条 / 架势 / 回血）

生成 HUD 后 **Ctrl+S 存场景**，再 Play。开局应看到：左上 Boss 血条+2 红点+名字、顶部黄条（空）、左下玩家血条+粉点和架势条（空）、右下绿色葫芦和数字。

| # | 操作 | 预期 |
|---|------|------|
| 1 | Play，先别动手 | 双方血条满；架势条空；葫芦数字 = PlayerConfig.GourdCount（默认 10）；左上 2 个红点 |
| 2 | 砍中 Boss | Boss 血条变短；Boss 顶部架势条从中间向两边变长 |
| 3 | 被 Boss 砍中（或自己硬吃） | 玩家血条变短；左下架势条从中间向两边变长 |
| 4 | 格挡挡住几刀 | 玩家血条基本不动，架势条上涨 |
| 5 | 先挨一刀再按 E 喝葫芦 | 玩家血条回升（默认一次 +300）；右下数字 -1 |
| 6 | 满血按 E | 播 `Drink`，右下数字 -1，血条仍满 |

条不动：看 CombatHUD 上 CombatUIController 的 Player Body / Boss Body 是不是场景里那两个人（不要拖 Prefab）。

其余表现（锁定白点、危字、回生/死亡字、音效）本轮先不挡，血条通了再验。

### 其余表现（后验）

| 项目 | 预期 |
|---|---|
| 血条 | 玩家/Boss 受伤血条下降 |
| 架势条 | 双向增长，快满高亮脉动 + 尖刺 |
| 忍杀灯 | 处决 1 命：Dot1 换成 DeadDot；再处决：Dot0 也换成 DeadDot |
| 回生花瓣 | 玩家死亡时熄灭 1 个 |
| 锁定点 | 锁定后 FocusOn 钉在 Spine1；绕圈/Boss 动作会跟着走；崩解切 Finsher；不被模型挡住 |
| "危"字 | Boss 危字招式弹出 + 红光 |
| 回生提示 | 死亡时"回生"字样 + 按键提示 |
| 死亡/胜利 | "死"字/重开提示、"胜利"文字 |
| 音效 | 打铁叮/笃、受击、危字、处决、回生、胜利 |
| BGM | 循环播放；Boss 第 2 命切曲（若配）；胜利切曲/停 |
| 震屏 | 完美弹反小抖、崩解大抖、处决强抖 |
| 顿帧 | 命中/弹反短暂停顿 |

## 五、受击动画接口（你要求的预留）

`CharacterConfig` 动画名字段 `HurtAnim_Normal / Heavy / Guard / GuardHeavy / Deflected`，**留空 = 回退**：GuardHeavy → Guard → Normal。格挡中挨打：`Knockback == 0` 播 `Hurt_Guard`（轻），`Knockback > 0` 播 `Hurt_GuardHeavy`（重）。裸吃时 `Knockback > 0` 才走 `HurtAnim_Heavy`。`Hurt_Guard` 与 `Deflect_Slash`（弹反成功）不是同一个。

## 六、常见坑速查

- **动画名没建 / 写错** → CrossFade 静默失败，角色"站着不动但逻辑在跑"。旧名 `Drink_Gourd`、`Death`、`Death_Pending` 已不用
- **子状态机里两个状态同名** → 切错或切不到
- **锁定走没有侧移** → 没进 `Walk_Strafe`，或融合树参数不是 `MoveX`/`MoveZ`
- **处决不触发** → 检查 `CombatManager.BossRef` + Boss 是否 `IsPostureBroken` + 距离 ≤ finisherRange(2m)
- **锁定无效** → 玩家没挂 `LockOnManager`，或 `BossRef` 没拖
- **松键还走** → Player Input 没勾 Auto-Switch，或 Default Map 不是 `Player`
- **UI 全没有** → 没跑 `Tools/战斗/生成战斗 HUD`，或生成后没存场景
- **血条不掉** → Controller 拖的是 Prefab 不是场景实例；或没打出伤害（Hitbox 层）
- **攻击打不出伤害 / 只有第一刀中** → 玩家 Hitbox 拖到**武器中央**；Boss Hurtbox 碰撞体**调到包住身体**；`targetLayers` 含对方层
- **前摇取消不了** → 该招 `AttackConfig.HitStartTime` 还是 0
- **切镜硬切 / 穿地 / 突然变焦** → Brain 混合时长太短或不是 EaseInOut；没 Inherit Position / Cylindrical Position；锁定 FOV 和 FreeLook 不一致。调 `CameraController.Blend Time`
- **锁定镜头穿墙** → `LockOn Camera` 没挂 `CinemachineCollider`；墙不在 Default/Ground 或没有碰撞体。不要把 Hurtbox 勾进 Obstacle Layers
- **镜头拧、跟着角色甩** → FreeLook Binding 不是 World Space，或 Follow 拖了玩家根
- **镜头走路发糊 / 老花眼** → Rig X Damping > 0，或 Heading 速度滤波还开着，或跟随点加了位置平滑。应阻尼 0、滤波 0、硬贴位置
- **侧向走狂抖、DeadZone 调大人又不居中** → Aim 还在用 Composer。改 Hard Look At，Follow/Look At 用 `CameraFollowTarget`
- **镜头走路抖（步伐扫画面）** → Brain 不要 Fixed Update；Follow 不要跟骨骼；Walk 的 Root Y 要 Bake Into Pose
