# 操作说明

支持**键鼠**与**手柄**，可在暂停菜单 → **设置** → **键位设置** 中修改。

## 键鼠

| 操作        | 按键            |
| ----------- | --------------- |
| 移动        | `W` `A` `S` `D` |
| 攻击        | 鼠标左键        |
| 防御 / 弹反 | 鼠标右键        |
| 垫步        | 左 `Shift`      |
| 跳跃        | 空格            |
| 葫芦        | `E`             |
| 锁定 / 解锁 | 鼠标中键        |
| 转动视角    | 移动鼠标        |
| 暂停        | `Esc`           |

> 防御键：**短按**弹反，**长按**格挡。

## 手柄

| 操作        | 按键       |
| ----------- | ---------- |
| 移动        | 左摇杆     |
| 攻击        | `RT`       |
| 防御 / 弹反 | `LT`       |
| 垫步        | `RB`       |
| 跳跃        | `A`        |
| 葫芦        | 十字键上   |
| 锁定 / 解锁 | 右摇杆按下 |
| 转动视角    | 右摇杆     |
| 暂停        | `Start`    |

> 未连接手柄时使用键鼠；连接后自动切换，可在键位设置里分别配置。
