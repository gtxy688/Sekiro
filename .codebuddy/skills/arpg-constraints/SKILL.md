# ARPG 项目约束（苇名之刃）— 引导入口

## 唯一事实源

**完整规范在项目根 `CLAUDE.md`**，包含：

- 架构红线 8 条（HFSM 层级、命中判定、数值归属、事件总线等）
- 代码规范（命名 / 文件组织 / 命名空间 / 数据结构 / 注释）
- 文档访问纪律 + 文档加载指引表
- 测试要求（不做自动化测试，交验收清单）

**本文件不复制上述任何条款。** 规范变更一律改 `CLAUDE.md`，本文件不动。

## 加载本 skill 后必须做

1. 读取项目根 `CLAUDE.md`（若本次会话尚未加载）
2. 按其中的「文档加载指引表」定位本任务对应的架构文档，**只读那一份**
3. 开发新模块前先在 `references/architecture-index.md`（本 skill 目录下）查模块归属与依赖图
4. 交付时附「验收清单」，**不自己宣称"完成"**

## 本 skill 存在的唯一理由

`CLAUDE.md` 是 always-load 的，但不保证在 skill 触发路径下已被读取；本 skill 只负责把会话引导过去，避免规范被绕过。

## 维护纪律

若发现本文件或 `CODEBUDDY.md` 与 `CLAUDE.md` 内容不一致，说明副本已过期——**报告用户，不要自行同步**。
