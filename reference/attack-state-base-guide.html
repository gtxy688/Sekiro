构造与 OnEnter（38、56 行）

构造函数经 base(body) 交给基类保存角色，自身保存 parent 和 config；构造不是开始运行。切换状态后状态机才调用 OnEnter。

  1. OnAttackEnter：让子类提前初始化；空中类记录进入时间。
  2. 空配置退回待机；清零本次进度、事件记录和攻击恢复标记。
  3. 缓存基础数值与 Boss 招式上下文，清掉已接手的 ActiveAttack 临时选择。
  4. ValidateWindows：要求时间顺序合法，并检查脉冲。
  5. 请求攻击动画；请求失败会打印错误，此分支本身没有立即退出。
  6. 清除旧的朝向冻结；允许转向时抑制动画根旋转并申请代码转向。
  7. 初始化武器开关后 ApplyHitbox，按当前动画时间与脉冲决定是否开窗；脉冲从 0 开始时也可能立即开启。
  8. 设置不可打断标记，并按需要发送危字事件。

OnUpdate 与结束条件（132 行）

落地保护和空配置检查之后，读取动画秒数，更新后摇开放标记，再调用 ApplyHitbox、ApplySfx、ApplyArrows、按配置更新转向。位移不在这个方法中逐帧计算。

AttackAnimClock 在过渡中优先找目标攻击的下一状态，否则找当前状态；匹配后使用 normalizedTime × length，找不到则返回 0。它不是进入状态后自行累计的墙钟。

  • WaitAnimEnd 为真：等待 IsAnimFinished。
  • 否则：到 StateDuration；或没有 NextCombo、最后判定已结束且动画播完；或没有有效近战判定且动画播完，满足任一条件就退出。
  • 动画结束检查要求第 0 层不在过渡中、状态名匹配、normalizedTime ≥ 1。

ApplyHitbox（399 行）

  1. CanMeleeHit 判断有无跨度至少 0.02 秒的有效脉冲。
  2. CurrentPulseIndex 找到满足 start ≤ animTime < end 的脉冲编号，找不到为 -1。
  3. 需要命中且尚未开启，或脉冲编号变化：必要时关旧窗、应用该段伤害、开启新窗并记录编号。
  4. 不需要命中但还开着：关闭并清掉状态侧标记。
  5. 同步 body.ActiveHitPulseIndex，供其他战斗规则读取。

Hitbox.Enable / SetConfig 会清理命中记录；只在必要时重开，才能兼顾“同段不重复打同一人”和“下一段可以再次命中”。本类协调判定时机，实际物理查询由 Hitbox 完成，命中仍交 CombatManager / CombatResolver 处理。

ApplyPulseCombat（429 行）交 AttackCombatResolve.ApplyPulse 写入本段数值。脉冲 overrideCombat 为真使用独立数值，否则使用缓存基础值。当前实现会修改 config 字段，不能把它解释为严格不可变配置。

HandleCommand 与子类钩子（182 行）

canCancel = animTime < HitStartTime 或 animTime ≥ RecoveryWindowStart。是否进入取消状态还取决于具体子类；父状态也可能先处理指令。

函数处理
CancelToDeflect（203）基类默认 false；地面 AttackState 在允许时切防御，并透传 PressId。
CancelToDodge（206）基类默认 false；地面 AttackState 在允许时切垫步。
HandleJumpCommand（209）基类默认 false；空中子类处理 Jump2，地面跳跃由父层处理。
HandleMoveCommand（212）默认只记录方向；地面子类在后摇且方向足够大时进入 MoveState。
HandleAttackCommand（218）普通攻击不重解释为忍杀；有 NextCombo 且处于闭区间 [RecoveryWindowStart, ComboWindowEnd] 时创建下一段，否则 false。
HandleFinisherCommand（239）玩家请求 CombatManager 尝试执行已经可用的忍杀，返回 true。

NewSelf（54）由子类决定新建地面还是空中攻击；ExitToIdle（51）由子类决定退出到地面 Idle 或继续滞空的 AirIdle；WantsImmediateLand（45）用于空中落地停止推进本刀。

阅读时的事实边界

ApplyHitbox 仅认 hitPulses；空数组不走单窗兜底。AnimUtil.TryBeginAttackAnim 当前通常按短名哈希请求 CrossFade，JumpThrust 特例用 Play；不要把注释中的旧路径规则当作现行代码。部分战斗数值有代码默认值。
