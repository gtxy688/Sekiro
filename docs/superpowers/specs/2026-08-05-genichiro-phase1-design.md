> 日期：2026-08-05
> 依据：`Docs/references/sekiro-genichiro-ai.md`（只狼天守阁弦一郎 Lua 行为反编译，素材来源）

## 一、目标

复刻只狼天守阁苇名弦一郎一阶段 Boss 战的核心战斗体验：玩家通过攻击、弹刀/格挡、闪避、识破、踩头等机制，将 Boss 架势打崩后进行忍杀。

## 二、范围（红线）

1. 仅一阶段：剑+弓，无雷电、无雷返、无二阶段。
2. 全量招式（7 大分类，见招式表），按里程碑分批实现，**M1 先跑通核心闭环**。
3. UI 无伤害数字（只狼没有伤害显示）。

## 四、玩家机制

攻击连斩、弹刀/格挡、闪避（无敌帧）、识破、踩头、跳跃、回血（药葫芦）、锁定目标。

## 五、Boss AI（依据 references 提炼，不逐帧还原）

### 5.1 距离分档选招（主动计划）

| 距离 | 招式（权重） | 备注 |
|------|-------------|------|
| >7m | 射箭+近身斩(600)、快速接近砍两刀(300) | 远距离牵制 |
| 5~7m | 接近砍两刀(300)、接近横砍+射箭(100)、飞渡浮舟(300) | 中远 |
| 3~5m | 横斩(5)、横二连斩(10)、横重斩(30)、旋转斩+肘击(15)、飞渡浮舟(300) | 中距离 |
| <3m | 位移横砍+转身(15)、旋转斩+肘击(15)、横斩+踢(30)、垫步后空中五连射(30) | 贴身 |
| 特殊 | 跳跃下刺(3022，≤5m 且条件满足) | 危字 |

**规则：** 架势条 ≤360 时，飞渡浮舟权重拉满 300（残架势更爱出招牌技）。

### 5.2 读指令（AI 对玩家动作的响应）

| 玩家动作 | Boss 响应 | references 依据 |
|---------|----------|----------------|
| 攻击 | 大概率进入防御/招架 | `Parry`：0.1s 防御冷却 |
| 连续攻击（连防次数↑） | 越倾向招架（EndureAttack） | `Get_ConsecutiveGuardCount` |
| 喝药 | 蓄力重箭打断 | `Interupt_Use_Item` → 3023 |
| 被弹刀 | 进入交锋反击（Kengeki） | `Kengeki_Activate` |

### 5.3 被弹刀反击（交锋计划）

- 距离 >2.5m → 无动作（NoAction）
- 近身 → 按连弹次数反打：砍一刀(3050/3076) / 二连斩(3068) / 突刺(3062) / 侧垫步+横重斩
- 血量 <75% → 额外可选飞渡浮舟完整版(3028)

## 七、技术底座（沿用 `Docs/architecture/` 决策）

1. FSM 状态机（`State`/`StateMachine` 基类），禁止 MonoBehaviour Update 手写 switch-case
2. `CombatEvents` 事件总线，Player/ 与 Boss/ 禁止互相直接引用
3. 战斗参数一律 ScriptableObject，`.cs` 内禁止硬编码数值
4. 命中判定用 `Physics.OverlapSphere`，禁止 OnTrigger/OnCollision 做攻击判定
5. 单一输入系统（新 Input System），禁止新旧混用
6. 单文件 ≤300 行；公开方法带 `/// <summary>`

## 八、实现里程碑

### M1（先行 · 核心闭环）
- 玩家：简单攻击 + 格挡/弹刀 + 架势 + 血条
- Boss：基础招式（横斩/横二连斩/横重斩/快速接近砍两刀）+ 技能出招 + **AI 读指令**（玩家攻击时 Boss 防御/招架）
- 目的：跑通「玩家攻击 ↔ Boss 防御 ↔ 架势变化 ↔ 忍杀」完整链路

### M2（危字与反制）
- 突刺 / 跳跃下刺 / 下段横扫 + 红「危」字 + 识破 + 踩头

### M3（招牌与变招）
- 飞渡浮舟（3040/3041） + 完整版（3028） + 旋转斩+肘击 / 横斩+踢 / 转身斩

### M4（弓系与机动）
- 射箭+近身斩 / 射两箭+斩 / 空中五连射 / 蓄力重箭（投射物）
- 垫步 / 接近横砍+射箭 / 弹刀反击全量

### M5（收尾）
- 药葫芦回血、锁定目标、HitStop 帧冻结、动画对接（2730 个 FBX）、数值实测调参

## 九、数值策略

references 无招式帧数据/伤害，**按只狼手感给一版合理默认参数**（前摇/判定/后摇、伤害、架势伤害、箭速、无敌帧等），全部进 ScriptableObject，用户进游戏实测后调整。
