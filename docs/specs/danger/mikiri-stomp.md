# 识破与踩头

## 识破判定 (Mikiri)

**全部满足才触发识破：**
1. `attackType == AttackType.Thrust`
2. `距离 < 3m`
3. `攻击方向与玩家朝向夹角 < 60°`
4. 在攻击 Active 帧内按 Shift
5. Shift + **无方向键**输入（默认前踏识破）

任一不满足 → 普通闪避 (DodgeState)

**成功效果：**
踩刀动画 → "咔嚓"音效 → 帧冻结 0.067s (4帧) → 屏幕震动 (振幅0.1, 0.2s) → 敌方架势+50 → 敌人硬直 0.5s → 可追击

**识破失败：**
- 突刺攻击没按 Shift → 被刺中，受伤+架势上升
- 非突刺按 Shift → 普通闪避（无惩罚）

## 踩头判定 (Stomp)

**条件：**
- 玩家处于下落阶段
- Y偏移 < 0.5m (在敌人头顶区域)
- 水平距离 < 1.5m

**满足→对敌方架势+30，帧冻结 0.05s (3帧)**
