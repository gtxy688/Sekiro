# Boss AI 决策逻辑

## 决策流程

每帧 `Execute()`：
1. 计算与玩家距离
2. 按行为权重表随机选招
3. 检查特殊触发条件覆盖
4. 出招

## 特殊条件

| 条件 | 行为 |
|------|------|
| 玩家喝药 | 大概率突进攻击 |
| 玩家架势将崩 | 激进攻击 |
| 玩家连砍 3 段+ | 60% 进入弹刀姿态 |
| 被玩家弹刀成功 | 短暂后退，下招大概率防御 |

## 行为权重表

| 行为 | 权重 | 条件 |
|------|------|------|
| 横斩/上挑 | 25% | 距离<3m |
| 三连斩 | 20% | 距离<2.5m |
| 突刺 | 15% | 距离<3.5m，随机 |
| 下劈 | 10% | 距离<2m |
| 跳跃劈 | 10% | 距离<4m |
| 扫击 | 5% | 距离<2m，偶尔 |
| 后撤+射箭 | 15% | 距离>4m 或 被连续攻击后 |

`SelectAttack(float distanceToPlayer, PlayerStateInfo playerState) → AttackData`
