# 输入优先级与打断规则

## 操作优先级（从高到低）

`忍杀 > 弹刀/格挡 > 攻击 > 识破/闪避 > 跳跃 > 回血 > 移动`

- 高优先级操作可打断低优先级动画
- 同优先级不可互打断（需等当前动作结束）
- 忍杀最高：架势归零时贴近按左键优先触发忍杀
- 弹刀优先于攻击：同时按左右键时执行弹刀

## 打断规则矩阵

| 当前状态 | 可被打断 |
|---------|---------|
| 攻击前摇 | 弹刀、闪避 |
| 攻击判定 | ❌ |
| 攻击后摇 | 弹刀、闪避、连招 |
| 闪避 | ❌ |
| 跳跃 | ❌ |
| 喝药 | 任意攻击、弹刀、闪避 |
| 受击硬直 | ❌ |
| 架势崩溃 | ❌ |
| 忍杀 | ❌ |
| 识破 | ❌ |
