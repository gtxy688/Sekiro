# 弹刀判定机制

## 流程

右键轻点→进入 DeflectState，持续 0.2s (12帧@60fps)
- 第 1-12帧：完美弹刀窗口
- 第 13-36帧：普通格挡窗口 (hold 不放则维持格挡)

## 判定

| 受击时机 | 结果 | 效果 |
|---------|------|------|
| 完美窗口内 | PerfectDeflect | 0伤害、自身姿势-8%、敌方架势+×倍率 |
| 格挡窗口内 | NormalBlock | HP×0.4、架势×0.3 |
| 窗口外 | None | 全额伤害 |

## 角度

攻击方向与玩家正面夹角 < 90° 才可弹刀（`IsAttackFromFront`），否则结果为 None。

## 碰撞检测

`Physics.OverlapSphere` 绑定在敌人武器骨骼上，每帧主动检测与主角弹刀判定框的交叉，不依赖 `OnTriggerEnter`。
