# 弹刀惩罚与加成

## 抖刀惩罚 (Spam Penalty)

- 触发：0.5s 内连续轻点右键且未成功弹刀
- 窗口缩小：每次 `windowReductionPerSpam=0.015s`
- 下限：`minDeflectWindow=0.016s` (1帧)
- 重置：成功弹刀 或 停止按键 >0.5s

## 连续弹刀加成 (Chain Bonus)

| 连续次数 | 对敌方架势伤害倍率 |
|---------|-----------------|
| 1 | ×1.0 |
| 2 | ×1.2 |
| 3 | ×1.4 |
| 4 | ×1.5 |
| 5+ | ×1.5 (封顶) |

- 重置：弹刀失败 或 超过 1s 未弹刀
